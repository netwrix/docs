title: Configuration
description: Set up what Access Analyzer scans and how it signs in, from sources and service accounts to agents, classifiers, and settings.
---

Configuration is the setup that scans depend on: the sources Access Analyzer reads, the service accounts it signs in with, the agents that run scans, the classifiers that Classification scans run, and the settings that apply to the whole installation. [Administration](../admin/index.md) covers scans themselves, because running and following scans is day-to-day work.
