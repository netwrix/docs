# View Private Groups in Directory Manager

This view lists only the private groups created in Directory Manager for the connected identity store. It doesn't list expired or deleted private groups. To view expired or deleted groups, see [View Expired Groups in Directory Manager](/docs/directorymanager/11.1/portal/group/allgroups/allexpiredgroups.md) or [Restore or Delete Groups in the Directory Manager Recycle Bin](/docs/directorymanager/11.1/portal/group/recyclebin/overview.md).

To search private groups, [Modify Search Directory](allgroups.md#modify-search-directory). To narrow the list, click **Private Group Grid Filters** and [Filter All Groups](allgroups.md#filter-all-groups). All the private groups that match the filters appear.
