# Approve, Deny, and Filter Requests in Directory Manager

Use the **All Requests** node to view workflow requests generated by enterprise users. The view
displays pending requests only.

You can click a column header to sort the requests by that attribute. For each request, you can view
the description, approvers, requester name, the target to change, status, the date the request was
made, and the reason the request was denied. Expand a request to view more details, such as the
field changed along with its old and new values.

What do you want to do?

- [Approve a request](#approve-a-request)
- [Deny a request](#deny-a-request)
- [ReRoute a request](#reroute-a-request)
- [Filter requests](#filter-requests)

## Approve a request

1. On the left navigation bar, click **Requests**. Then click the **All Requests** tab to view the
   workflow requests that are pending approval.

    You can expand a request to view its details.

2. Select a request and click **Approve Requests** to approve it.

    Directory Manager processes the request and runs the changes.

## Deny a request

1. On the left navigation bar, click **Requests**. Then click the **All Requests** tab to view the
   workflow requests that are pending approval.

    You can expand a request to view its details.

2. Select the request you want to deny, enter the reason for denial, and click **Deny Request**.

    Directory Manager doesn't perform any action and makes no changes.

## ReRoute a request

To reroute a request to a different approver, follow these steps:

1. On the left navigation bar, click **Requests**. Then click the **All Requests** tab to view the
   workflow requests that are pending approval.

    You can expand a request to view its details.

2. Select the request you want to reroute and click **ReRoute**.
3. In the **Reroute Workflow Request** wizard, select one of the following:

    - Manager of User
    - Manager and Additional Manager of User
    - Other

        Search for any user and select them from the search list.

4. Click **Reroute** to close the wizard.

## Filter requests

1. On the **Requests** page, use the following areas to specify criteria for filtering the
   list of requests.

    - Requesters
    - Approvers
    - Date
    - Actual Approver / Denier
    - Target Object
    - Request Status

2. From the **Requesters** list, select an option:

    - **All:** view requests made by all users.
    - **Custom:** view requests made by the specific users listed in the **Custom Requesters** box.

3. From the **Approvers** list, select an option:

    - **All:** view requests approved by all users.
    - **Custom:** view requests approved by the specific users listed in the **Custom Approvers** box.

4. Use the **Date** list to specify the period you want to view requests for.

    - All
    - Today
    - Yesterday
    - Last 7 Days
    - Last 30 Days
    - Last 90 Days

        The page displays requests that were initiated in the given period.

5. From the **Actual Approver/Denier** list, select an option:

    - **All:** view requests approved or denied by all users.
    - **Custom:** view requests approved or denied by the specific users listed in the **Custom Actual
      Approvers/Deniers** box.

6. From the **Target Object** list, select an option:

    - **All:** view requests related to all types of objects.
    - **Custom:** view requests related to the specific objects listed in the **Custom Target Object**
      box.

7. From the **Request status** list, select an option:

    - **Pending**: view requests that are pending your approval or denial.
    - **Approved**: view requests that you have approved.
    - **Denied**: view requests that you have denied.
    - **All**: view all pending, approved, and denied requests.

8. To add more filters, click **Add Filter**.
9. From the **Select a filter** list, select any of the following to search for relevant requests:

    - Description
    - Workflow Event
    - Workflow Type

10. Two more boxes appear next to the **Select a filter** box after you select a filter.

    - **Select an Operator**: select the operator that is relevant to your filter.
    - **Select a Value**: specify the value for the selected operator in the first box.

11. Click **Apply**.

    The page displays workflow requests that match the specified criteria.

12. Click **Reset Filter** to remove the filters that you added.

    The page displays all workflow requests again.
