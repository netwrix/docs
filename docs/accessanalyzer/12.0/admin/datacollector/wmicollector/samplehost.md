# WMICollector: Sample Host

On the Sample Host page, enter a sample host to populate options for the query.

![WMI Browser wizard Sample Host page](/images/accessanalyzer/12.0/admin/datacollector/wmicollector/samplehost.webp)

On the Sample Host page, if the classes and namespaces you want to audit reside on the local host,
click **Next**. (A period (`.`) represents the local host in the **Sample host name** box). If you need
a different sample host to populate the namespace and class options, enter the name for the
remote host and click **Next**.
