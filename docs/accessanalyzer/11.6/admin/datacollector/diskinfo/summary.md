# DiskInfo: Summary

The Summary page displays a summary of the configured query.

![Disk Info wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/diskinfo/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** to close
the Disk Info Data Collector Wizard and avoid saving accidental clicks.
