# ExchangeMailbox: Properties

Use the Properties page to select the properties to gather. The available properties
depend on the category selected. It is a wizard page for all of the categories.

![Exchange Mailbox Data Collector Wizard Properties page](/images/accessanalyzer/11.6/admin/datacollector/exchangemailbox/properties.webp)

Select properties individually, or use the **Select All**, **Clear All**, and **Reset All**
buttons. The data collector gathers all selected properties. Click **Message Classes** to open the Message
classes filters window.

![Message classes filters window](/images/accessanalyzer/11.6/admin/datacollector/exchangemailbox/messageclassesfilterswindow.webp)

The wildcard (`*`) returns all message class filters. Enter the name of the class filter and click
**Add** to add it to the list. **Delete** will remove the selected class filter from the list. The
**Load defaults** option will restore the class filter default settings.
