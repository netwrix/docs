# GPO Monitoring Dashboard

The GPO Monitoring dashboard contains the following cards:

![GPO Monitoring Dashboard](/images/threatprevention/7.5/siemdashboard/splunk/activedirectory/dashboard/gpomonitoring.webp)

- Top GPOs – Shows the top five Group Policy Objects associated with events in the specified timeframe
- Successful/Blocked Events – Breakdown of Group Policy Object changes by successful, failed, or blocked status in the specified timeframe
- Changes by Domain – Breakdown of Group Policy Object changes by domain in the specified timeframe
- Change Details – Tabular format of all Group Policy Object change events in the specified timeframe

The timeframe defaults to the last 24 hours (past day).
