# The Get started page

The Get started page is where AI Security opens until your organization has a source connected. It says what AI Security does, and you start the first run from it.

## Open the Get started page

1. In the 1Secure sidebar, select **AI Security**. While no source is connected, the **Get started** page opens, titled "Discover your AI agents".

   ![Get started page with the Discover every agent, Understand what each can do, and Decide and keep a record cards and the Get started button](/images/1secureaisecurity/getting-started/get-started-page.webp)

The three cards say what the first run sets up.

| Card | What it says |
|------|--------------|
| Discover every agent | Find agents in Microsoft 365, cloud AI, automation tools, and voice services. |
| Understand what each can do | See what each agent can do and the data it can reach. |
| Decide and keep a record | Assign an owner and keep a record you can share with auditors. |

## Start the first run

1. Click **Get started**. The first run opens on **Choose where to look**.

A bar at the top shows the steps of your run: **Choose where to look**, **Connect Microsoft** when you choose the Microsoft row, **Connect other sources** when you choose any other platform, and **Start your first scan**.
