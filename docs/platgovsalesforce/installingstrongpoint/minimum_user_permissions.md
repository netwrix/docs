# Minimum User Permissions

Strongpoint requires the following system permissions in addition to the **Minimum Access -
Salesforce** standard profile. The table lists each permission and whether Strongpoint needs it to
run the scanners, to configure the Data Tracking tool, or both.

Assign these permissions before you [set access and permissions](/docs/platgovsalesforce/installingstrongpoint/setting_access_permission.md)
for a user.
