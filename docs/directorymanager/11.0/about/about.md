# GroupID Installation Overview

The GroupID installer automatically detects the prerequisite software and Windows features
that GroupID requires, and installs them without any manual intervention. This simplifies
GroupID installation, reduces workloads, and shortens installation time.

GroupID configuration and upgrade are also integrated into the installation experience.
