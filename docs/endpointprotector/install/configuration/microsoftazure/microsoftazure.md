# Microsoft Azure

This section explores the integration of Endpoint Protector into your Azure environment. You won't find Endpoint Protector readily available in the Azure Marketplace, but this guide walks you through acquiring the specialized Virtual Machine (VM) tailored for your Azure setup. From creating the Storage Account and Container to configuring the Disk and Virtual Machine, you'll complete your Azure deployment.
