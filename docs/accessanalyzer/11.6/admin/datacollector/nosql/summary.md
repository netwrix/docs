# NoSQL: Summary

Use the Summary page to review a summary of the configuration settings. It is a wizard page for all
of the categories.

![NoSQL Data Collector Wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/nosql/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel**
instead to close the NoSQL Data Collector Wizard without saving accidental clicks.
