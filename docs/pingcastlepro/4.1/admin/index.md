# PingCastle Pro administration

This section covers day-to-day administration of PingCastle Pro. The application has two areas:

- **Audit data** — The [technical view](technical-view.md). It shows the PingCastle report for each imported domain, with its history, timeline, and cartography.
- **Configuration** — The [configuration view](configuration-view/index.md). Use it to manage exceptions and import reports.
