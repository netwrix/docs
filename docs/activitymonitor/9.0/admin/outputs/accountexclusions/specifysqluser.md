# Specify Sql User Name Window

This window opens when you need to specify a SQL Server account in a field.

![specifysqlusernamewindow](/images/activitymonitor/9.0/admin/outputs/window/specifysqlusernamewindow.webp)

Enter the SQL Server user name into the text box. Multiple user names can be added using a semicolon
(;), a comma (,), or a space. Then click OK. The Specify Sql User name window closes, and the
system adds the account to the field.
