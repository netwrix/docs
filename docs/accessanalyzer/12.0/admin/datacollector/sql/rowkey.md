# SQL: Rowkey

The Rowkey page configures the Rowkey for the SQL query. It is a wizard page for the Custom Query
categories.

![SQL Data Collector Wizard Rowkey Page](/images/accessanalyzer/12.0/admin/datacollector/sql/rowkey.webp)

The Rowkey page lists properties selected on the Results page. Select the property or properties to
act as the Rowkey. You can select properties individually, or use the **Select All** and **Clear
All** buttons.
