# Directory Manager Portal General Features

The Directory Manager portal provides these general features for users:

- Directory search
- Find dialog box
- Portal settings
- User account settings
- Toolbars

## Directory search

The Directory Manager portal provides a search feature that lets users manage directory objects in their identity store. These objects include mailboxes, users, groups, and contacts. After a search, the results appear on the Search Results page.

See the [Search Directory Objects in the Directory Manager Portal](/docs/directorymanager/11.2/portal/generalfeatures/search.md) topic for more information.

## Find dialog box

With the **Find** dialog box, you can search User, Group, and Contact objects in the connected identity store. The object types available for search can vary, depending on the page you launch the **Find** dialog box from.

See the [Find Users, Groups, and Contacts in Directory Manager](/docs/directorymanager/11.2/portal/generalfeatures/find.md) topic for more information.

## Portal settings

The Directory Manager portal offers portal settings that customize the user experience for each user.

See the [Configure Directory Manager Portal Settings](/docs/directorymanager/11.2/portal/generalfeatures/portal.md) topic for more information.

## User account settings

Users can manage their own profile information and perform account-related actions through User Settings.

See the [Manage Your Directory Manager User Account](/docs/directorymanager/11.2/portal/generalfeatures/user.md) topic for more information.

## Toolbars

The portal provides toolbars with options that users can use on objects. These actions include editing properties, managing membership, and viewing history.

See the [Directory Manager Portal Toolbar Buttons](/docs/directorymanager/11.2/portal/generalfeatures/toolbar.md) topic for more information.
