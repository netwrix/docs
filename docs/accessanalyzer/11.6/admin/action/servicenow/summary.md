# ServiceNow Action: Summary

The Summary page displays a summary of the configured query.

![ServiceNow Action Module wizard Summary page](/images/accessanalyzer/11.6/admin/action/servicenow/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the ServiceNow Action Module Wizard without saving accidental clicks.
