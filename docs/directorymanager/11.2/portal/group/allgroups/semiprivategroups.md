# View Semi-Private Groups in Directory Manager

This view lists only the semi-private groups created using Directory Manager in the connected
identity store. It doesn't list expired or deleted semi-private groups. To view the expired or
deleted groups, select the [View Expired Groups in Directory Manager](/docs/directorymanager/11.2/portal/group/allgroups/allexpiredgroups.md) or
[Restore or Delete Groups in the Directory Manager Recycle Bin](/docs/directorymanager/11.2/portal/group/recyclebin/overview.md) respectively.

You can [Modify Search Directory](allgroups.md#modify-search-directory) to search semi-private
groups and add [Filter All Groups](allgroups.md#filter-all-groups) by clicking **Private Group Grid
Filters**. All the semi-private groups matching the filters appear.
