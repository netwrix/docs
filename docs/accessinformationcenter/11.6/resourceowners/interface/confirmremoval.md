# Confirm Removal Window

Removing a resource from the Resource Owners interface disassociates the owners from the resource but doesn't delete the resource from the database or reports. The system retains all action history for that resource but cancels pending actions, which may include outstanding reviews or access requests.

To remove a resource from being managed through the application:

**Step 1 –** In the Resource Owners interface, select the resource and click Remove. The Confirm
Removal window opens.

![Confirm Removal window asking are you sure you want to remove](/images/threatprevention/7.4/admin/configuration/collectionmanager/confirmremoval.webp)

**Step 2 –** Click Yes to complete the removal process or **No** to cancel it.

The resource no longer appears in the Resource Owners interface.
