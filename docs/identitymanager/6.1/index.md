# Netwrix Identity Manager

To learn about Netwrix Usercube and build the solution you need, explore our guides.

The present documentation mentions the Netwrix Usercube application as simply Usercube.

**Usercube's guides** include:

- An [Introduction Guide](/docs/identitymanager/6.1/introduction-guide/index.md) if you
  are new to Usercube.
- A [User Guide](/docs/identitymanager/6.1/user-guide/index.md) to configure Usercube
  from scratch via the UI.
- An [Integration Guide](/docs/identitymanager/6.1/integration-guide/index.md) to
  complete Usercube's configuration in XML according to your needs.
- An [Installation Guide](/docs/identitymanager/6.1/installation-guide/index.md) to
  install Usercube in a production environment.
- A [Migration Guide](/docs/identitymanager/6.1/migration-guide/index.md) to upgrade to
  a new version of Usercube.
