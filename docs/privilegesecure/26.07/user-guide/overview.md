# User guide overview

This section is for people who use Privilege Secure to get access, rather than to configure it. You work in the console in a browser, in your own Remote Desktop or SSH client, or in the browser extension.

Every person who signs in is a user. Approvers, reviewers, and auditors do the tasks of a user and some extra tasks. The roles in the console are Administrators, Users, Reviewers, and Auditors. An approver isn't a role. The approvers for a request are the users and groups that the approval workflow of the connection profile names.

## What each audience can do

| Audience | Tasks | Pages |
|---|---|---|
| Users | Sign in, find activities, request sessions, connect, and track your sessions. | [Sign in](/docs/privilegesecure/26.07/user-guide/sign-in.md), [My Activities](/docs/privilegesecure/26.07/user-guide/my-activities.md), [Request a session](/docs/privilegesecure/26.07/user-guide/request-session.md), [Connect to a session](/docs/privilegesecure/26.07/user-guide/connect-session.md), [Track your sessions](/docs/privilegesecure/26.07/user-guide/my-sessions.md) |
| Approvers | Approve or deny the requests that wait for you. | [Approve or deny session requests](/docs/privilegesecure/26.07/user-guide/approve-requests.md) |
| Reviewers | Certify or deny access in an access certification. | [Review an access certification](/docs/privilegesecure/26.07/user-guide/review-access.md) |
| Auditors | Watch live sessions and replay recorded sessions in your scope. | [Review sessions as an auditor](/docs/privilegesecure/26.07/user-guide/audit-sessions.md) |

## Ways to connect

- **The console.** Request a session in the console, then launch it from there. See [Connect to a session](/docs/privilegesecure/26.07/user-guide/connect-session.md).
- **Your own client.** Use Remote Desktop or an SSH client such as PuTTY instead of the browser. See [Connect with your own RDP or SSH client](/docs/privilegesecure/26.07/user-guide/connect-own-client.md).
- **The browser extension.** Start web sessions from Chrome or Edge. See [Browser extension](/docs/privilegesecure/26.07/user-guide/browser-extension/browser-extension.md).
- **From outside the network.** Open RDP and SSH sessions in a browser through the Remote Access Gateway portal. See [Sign in to the Remote Access Gateway portal](/docs/privilegesecure/26.07/remote-access-gateway/user-guide/sign-in.md) and [Browser sessions](/docs/privilegesecure/26.07/remote-access-gateway/user-guide/browser-sessions.md).

If your organization uses ServiceNow, you can enter a ticket for a session and update the ticket when the session ends. See [Use ServiceNow tickets with sessions](/docs/privilegesecure/26.07/user-guide/servicenow-tickets.md).

## Before you begin

Get the console address from your administrator, and see [Navigate the console](/docs/privilegesecure/26.07/user-guide/navigate-console.md) to learn the layout. For the concepts behind activities, access policies, and sessions, see [Key concepts](/docs/privilegesecure/26.07/getting-started/key-concepts.md).
