# View Private Groups in Directory Manager

This view lists only the private groups created using Directory Manager in the connected identity
store. It doesn't list expired or deleted private groups. To view the expired or deleted groups,
select the [View Expired Groups in Directory Manager](/docs/directorymanager/11.0/welcome/group/allgroups/allexpiredgroups.md)
or [Restore or Delete Groups in the Directory Manager Recycle Bin](/docs/directorymanager/11.0/welcome/group/recyclebin/overview.md)
respectively.

You can [Modify Search Directory](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#modify-search-directory) to search private groups and add
[Filter All Groups](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#filter-all-groups) by clicking **Private Group Grid Filters**. All the private groups matching
the filters appear.
