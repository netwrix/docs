# Policy Tab

This tab shows detail on current and previous compliance assessments, including details of any
failures.

![compliancepolicytab](/images/changetracker/admin/tabs/compliancepolicytab.webp)

- **Timeline** – Click to see the detail for previous compliance assessments.
- **Group Performance** – Shows an overall comparison of current and previous results for all
  systems within the group. Click either column to see the detail view for the selected report run.
- **Device Scores** – Bars show the distribution of device count for each scoring band, highlighting
  the most common failures. Click any bar to see the detail view for the selected score range.
- **Options** – Run a new report or view/export previous reports.
- **Failures Analysis** – Headline details of failures with the highest incidence.
