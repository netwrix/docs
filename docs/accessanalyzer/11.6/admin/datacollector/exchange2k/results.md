# Exchange2K: Results

Use the Results page to select properties to gather. It is a wizard page for
all.

![Exchange 2K+ Data Collector Wizard Results page](/images/accessanalyzer/11.6/admin/datacollector/exchange2k/results.webp)

Select properties individually, or use the **Check All**, **Uncheck All**, or **Reset Defaults**
buttons. The data collector gathers all selected properties. Click **Expand All** to expand all
properties, or **Collapse All** to collapse all properties. Available properties vary based on the
category selected.
