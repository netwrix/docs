# View Your Microsoft Teams in Directory Manager

This page lists all the Microsoft Teams groups that you own.

To search your teams, [Modify Search Directory](/docs/directorymanager/11.2/portal/group/allgroups/allgroups.md#modify-search-directory). To narrow the list, click **My Teams Grid Filters** and add [Filter All Groups](/docs/directorymanager/11.2/portal/group/allgroups/allgroups.md#filter-all-groups). All the teams that match the filters appear.
