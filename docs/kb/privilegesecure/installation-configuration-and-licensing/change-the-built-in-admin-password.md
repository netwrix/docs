# Changing the Built-In Admin Password

## Overview

This article describes how to change the password of the built-in Admin account in Netwrix Privilege Secure for Access Management.

## Instructions

1. Sign in to Privilege Secure using the Admin account.

   ![A filled-in log-in form for the Privilege Secure web interface.](./../0-images/ka04u000000HdF3AAK_1.png)

   > **IMPORTANT:** The `Domain` field must be set to `"<none>"` to log in with the built-in Admin account.

2. In the upper-right of the page, click **Admin** and then **Settings**.

   ![The user settings dropdown menu in Privilege Secure.](./../0-images/ka04u000000HdF3AAK_2.png)

3. Use the **Change Password** menu that appears on the page to set a new password for the built-in Admin account.

   ![The Change Password form for the Privilege Secure built-in Admin account.](./../0-images/ka04u000000HdF3AAK_3.png)

   If the password change is successful, you are immediately logged out of Privilege Secure and presented with the log-in page.

   > **IMPORTANT:** Previously used passwords cannot be used and result in an error when you attempt to change the password.
