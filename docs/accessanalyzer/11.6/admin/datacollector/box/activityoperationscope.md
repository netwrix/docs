# Box: Activity Operation Scope

Use the Activity Operation Scope page (ActivityOperationScope) to select or unselect Box Enterprise
events for scans. It is a wizard page for the Scan Box Activity category.

![Box DC Wizard Activity Operation Scope page](/images/accessanalyzer/11.6/admin/datacollector/box/activityoperation.webp)

You can select event filters by group, or expand the group and select filters individually.
Enterprise Auditor gathers all selected filters from the Box environment.

Event filters include:

- Collaboration
- File Activity
- Group
- Login
- Metadata
- Misc
- Security
- Sharing
- Task
- Users
- Workflow
