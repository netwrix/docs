# Integrations and API

Use these pages to connect Endpoint Protector to other systems and to automate it.

- [EPP REST API](/docs/endpointprotector/integrations/epp_rest_api/eppapi.md)—automate administration over HTTPS, with OAuth 2.0 authentication and a reference built into every server
- [API Clients](/docs/endpointprotector/integrations/epp_rest_api/apiclients.md)—create the clients that your integrations use to call the REST API
- [Directory Services](/docs/endpointprotector/integrations/directoryservices/directoryservices.md)—connect Endpoint Protector to Active Directory and Microsoft Entra ID
- [SCIM API](/docs/endpointprotector/integrations/directoryservices/scimapi.md)—provision users and groups with the System for Cross-domain Identity Management
- [SIEM Integration](/docs/endpointprotector/admin/appliance.md#siem-integration)—send log entries to a security information and event management server as syslog messages
- [Single Sign-On](/docs/endpointprotector/admin/systemconfiguration/singlesignon/singlesignon.md)—sign in to the console through an identity provider
