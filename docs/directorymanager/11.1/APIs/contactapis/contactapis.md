# Directory Manager Contact APIs

Directory Manager provides the following APIs to perform contact-specific functions:

- [Create a Contact with the Directory Manager API](/docs/directorymanager/11.1/APIs/contactapis/createcontact.md)
- [Delete a Contact with the Directory Manager API](/docs/directorymanager/11.1/APIs/contactapis/deletecontact.md)
- [Delete Multiple Contacts with the Directory Manager API](/docs/directorymanager/11.1/APIs/contactapis/deletecontacts.md)
- [Get a Contact with the Directory Manager API](/docs/directorymanager/11.1/APIs/contactapis/getcontact.md)
- [Get Contacts API in Directory Manager](/docs/directorymanager/11.1/APIs/contactapis/getcontacts.md)
- [Update a Contact API in Directory Manager](/docs/directorymanager/11.1/APIs/contactapis/updatecontact.md)

:::note
The contact object type isn't supported in a Microsoft Entra ID-based identity store.

:::
