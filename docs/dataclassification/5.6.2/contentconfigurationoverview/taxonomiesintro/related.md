# Related

Use the Related tab to view and modify the non-hierarchical relationships between preferred
terms. This tab will only appear if the taxonomy is in SQL, as the SharePoint Term Store doesn't
support this functionality.

![relatedtermstab](/images/dataclassification/5.6.2/relatedtermstab.webp)

When a term is located in multiple branches of the taxonomy (a polyhierarchical taxonomy) – the
Related tab will also display each of the locations so you can jump to the specific branch.
