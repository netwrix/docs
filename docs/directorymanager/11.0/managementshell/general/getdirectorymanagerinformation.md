# Get GroupID Information Cmdlet

The **Get-GroupIdInformation** cmdlet retrieves general information about GroupID.

## Syntax

```
Get-GroupIdInformation
[<CommonParameters>]
```

## Required Parameter

- None

Example 1:

This example displays the name of the database and the name of the SQL Server that GroupID uses, the
GroupID version, and its installation path.

```
Get-GroupIdInformation
```
