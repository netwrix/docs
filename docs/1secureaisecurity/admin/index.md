# Administration

AI Security finds the AI agents and non-human identities on the platforms you connect to it. Each connected platform is a source. Use these pages to operate AI Security after your sources are connected.

- [Scans](/docs/1secureaisecurity/admin/scans.md) explains how to start, follow, stop, and retry scans, read the scan drawer, and respond when a source is read only in part.
- [Settings](/docs/1secureaisecurity/admin/settings.md) sets how scans run, how long results are kept, which rules raise issues, and which alerts you receive.
- [AI Security pages](/docs/1secureaisecurity/admin/pages/index.md) explains what each page, card, tab, and column shows.
