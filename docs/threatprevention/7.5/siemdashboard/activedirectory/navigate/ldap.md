# LDAP Dashboard

The Lightweight Directory Access Protocol (LDAP) dashboard contains the following cards:

![LDAP Dashboard](/images/threatprevention/7.5/siemdashboard/splunk/activedirectory/dashboard/ldap.webp)

- Top Client IPs – Shows the top five client IP addresses associated with LDAP events in the specified timeframe
- Top Perpetrators – Shows the top five users associated with LDAP events in the specified timeframe
- Change Events – Tabular format of all non-trivial LDAP queries in the specified timeframe

The timeframe defaults to the last 24 hours (past day).
