# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Product Overview

PingCastle Community documentation. Community is the command-line assessment tool with no web server. PingCastle is split into three sibling products, each with its own docs tree: `docs/pingcastleenterprise/`, `docs/pingcastlepro/`, and `docs/pingcastlecommunity/`. The first Getting Started page of each states which edition it covers and links to the other two.

## File Structure

- `4.0/` follows the section guide zones: `getting-started/`, `requirements/`, `install/`, `migration/`, `configuration/`, `admin/`, `integrations/`, `troubleshooting/`, with only the zones that apply.
- `3.5/` is the legacy flat layout. Don't restructure it.
- `3.5/` is the single page `index.md`.

Sidebars are autogenerated (`sidebars/pingcastlecommunity/<version>.js`). Order comes from `_category_.json` and `sidebar_position`.

Images go in `static/images/pingcastlecommunity/<version>/`.


## Terminology

Use these exact product names, and don't abbreviate or invent variants: PingCastle Enterprise, PingCastle Pro, PingCastle Community (also called PingCastle Standard and PingCastle Basic in older material), PingCastle for Service Providers.

"Active Directory" and "Entra ID" are always capitalized. Never use "AD" alone without spelling it out first.
