# Directory Manager 11.1 System Requirements

This page lists the hardware, operating system, Microsoft Exchange, and database requirements for running Directory
Manager 11.1. The prerequisites may vary depending on your environment.

- [Directory Manager Hardware Requirements](/docs/directorymanager/11.1/requirements/hardware.md)
- [Windows Server Requirements for Directory Manager ](/docs/directorymanager/11.1/requirements/windowsserver.md)
- [Directory Manager Supported Exchange Servers](/docs/directorymanager/11.1/requirements/exchangeservers.md)
- [Directory Manager Database Requirements](/docs/directorymanager/11.1/requirements/database.md)

Before installation, the [Run the Directory Manager Preparation Tool](/docs/directorymanager/11.1/install/installer/preparationtool.md) installs the
required software and Windows features. See the
[Software the Directory Manager Preparation Tool Installs](/docs/directorymanager/11.1/install/installer/whatprepinstall.md) topic for the list
of components the tool installs.
