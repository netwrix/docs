# Choose a Job Collection Template in Directory Manager

When you create a job, Directory Manager Synchronize creates a new job collection based on your settings and criteria. You can also use multiple templates to create a job collection directly.

**Follow these steps:**

1. In the Directory Manager portal, select **Synchronize** in the left pane.
2. In the Synchronize portal, click **Create New** and then click **Job Collection**.
3. On the **Choose Your Job Collection Template** page, enter the job collection details. Select whether to use a job group template or create a new job group.
4. Click **Next step**.
