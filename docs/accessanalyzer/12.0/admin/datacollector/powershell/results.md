# PowerShell: Results

The Results page provides configuration settings for the Properties to return and ROWKEY's
components.

![PowerShell Data Collector Wizard Results page](/images/accessanalyzer/12.0/admin/datacollector/powershell/results.webp)

The Results page options are:

- Properties to return – List of available properties to gather for the PowerShell query
- ROWKEY's components – List of available properties that Access Analyzer uses to build ROWKEY
