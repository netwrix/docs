# Create a Data Source API in Directory Manager

Use this API to create data sources for the supported providers. Data sources are
primarily used in Synchronize jobs, but you can also use them in queries to search for directory
objects and in queries for group membership update.

- [Create a Text/CSV Data Source with the Directory Manager API](/docs/directorymanager/11.1/APIs/datasourceapis/createds/dstext.md)
- [Create an MS Access Data Source with the API](/docs/directorymanager/11.1/APIs/datasourceapis/createds/dsaccess.md)
- [Create an MS Excel Data Source with the API](/docs/directorymanager/11.1/APIs/datasourceapis/createds/dsexcel.md)
- [Create an ODBC Data Source with the API](/docs/directorymanager/11.1/APIs/datasourceapis/createds/dsodbc.md)
- [Create an Oracle Data Source with the Directory Manager API](/docs/directorymanager/11.1/APIs/datasourceapis/createds/dsoracle.md)
- [Create a SQL Server Data Source with the Directory Manager API](/docs/directorymanager/11.1/APIs/datasourceapis/createds/dssql.md)
