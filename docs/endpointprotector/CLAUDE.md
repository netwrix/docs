# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Product

**Netwrix Endpoint Protector** is a data loss prevention (DLP) and device control product. Administrators define policies in a central web console, and client software on each Windows, macOS, and Linux endpoint enforces them. Its modules are Device Control, Content Aware Protection (including network content inspection), eDiscovery, and Enforced Encryption (EasyLock).

Use "Netwrix Endpoint Protector" on first reference. The existing pages mix "Endpoint Protector Client" and "EPP Client" (and the same for Server). Match the page you are editing.

## Versions

This product has **one version** and no version folder. Pages live directly under `docs/endpointprotector/`. The sidebar is autogenerated from the folder tree (`sidebars/endpointprotector/epp.js`), so a new page needs no sidebar edit.

## Terminology

Use "allowlist" and "denylist", not "whitelist" and "blacklist". Don't use "cososys", the former vendor name, in documentation.

## Open conflicts

Don't resolve these without the product owner:

- `requirements/client.md` says the client uses no kernel drivers or extensions. The client code builds Windows kernel drivers, and macOS uses a system extension.
- The Windows, macOS, and Linux client versions are tracked separately and don't always match.
