# Virtual Appliance Formats

platforms. The table below provides a list of supported virtual environments, versions, and main
formats.

## Virtual Appliance Compatibility

The Endpoint Protector (EPP) Server image ships in two formats: Open Virtualization Format (OVF) for VMware and Virtual Hard Disk (VHD) format for Microsoft Hyper-V. Both formats enable flexible testing and implementation. The Endpoint Protector Virtual Appliance can also run on other versions of supported virtualization software; however, the customer administrator is responsible for converting and maintaining the EPP Server image in those environments. Netwrix doesn't provide custom virtualization formats upon request.

The most commonly used format is OVF, as it works with the majority of virtualization software, including VMware vSphere (ESXi), VMware Workstation, VMware Fusion, VMware Player, and Oracle VM VirtualBox. The VHD format is intended for use within the Microsoft Hyper-V ecosystem
