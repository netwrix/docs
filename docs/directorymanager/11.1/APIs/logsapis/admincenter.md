# Download Admin Center Logs with the API

Use this API to get Admin Center logs. See the [Download Directory Manager Logs from Admin Center](/docs/directorymanager/11.1/admincenter/general/logs.md) topic
for additional information.

## Endpoint

**https://machinename:4443/AdminCenter/api/Logs/Download**

## HTTP Method

**GET**

### Sample Response Syntax

```
<Encrypted response>
```

Save the encrypted response as a zip file to a desired location.
