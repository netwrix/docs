# Change Share Permissions

Use the Change Share Permissions Parameters page to specify the permission status to change for the
selected group or users.

![File System Action Module Wizard Change Share Permissions Parameters page](/images/accessanalyzer/12.0/admin/action/filesystem/parameters/changesharepermissions.webp)

Select the options you want for changing the permissions control of the selected group or users.
