# View Expiring Groups in Directory Manager

This page shows only the expiring groups in the connected identity store.

Groups that expire in 30 days or less are expiring groups. Directory Manager calculates the expiry date from a group's expiry policy. The Group Lifecycle job expires these groups on their expiry dates. You can also manually expire a group before its expiry date.

To search expiring groups, [modify the search directory](allgroups.md#modify-search-directory). To filter the list, [add filters](allgroups.md#filter-all-groups) by clicking **Expiring Group Grid Filters**. All the expiring groups that match the filters appear.
