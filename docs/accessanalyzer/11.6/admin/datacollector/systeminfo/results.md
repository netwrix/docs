# SystemInfo: Results

Use the Results page to select which properties to gather from those available for the category.
It's a wizard page for all categories.

![System Info Data Collector Wizard Results page](/images/accessanalyzer/11.6/admin/datacollector/systeminfo/results.webp)

Select properties individually, or use the **Check all**, **Uncheck all**, and **Reset to
defaults** buttons. Enterprise Auditor gathers all selected properties. Available properties vary
based on the selected category.
