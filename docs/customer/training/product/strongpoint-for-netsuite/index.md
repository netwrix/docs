There are two learning paths for <NSN />, formerly <NPGN />:

* [Netwrix Strongpoint for NetSuite Learning Path](./core.md) – Take this learning path if your company is new to this application. By default, the Learning Library enrolls you in this learning path.
* [Netwrix Strongpoint for NetSuite – Onboard New NetSuite Admins Learning Path](./new-admin.md) – Take this learning path if your company already uses the application but it is new to you. You can find this learning path in the Learning Library.
