# Web Request: Summary

The Summary page displays a summary of the configured action.

![Web Request Action Module Wizard Summary page](/images/accessanalyzer/12.0/admin/action/webrequest/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel** to
close the Web Request Action Module Wizard instead. This prevents the wizard from saving accidental
clicks.
