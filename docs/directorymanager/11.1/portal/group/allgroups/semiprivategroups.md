# View Semi-Private Groups in Directory Manager

This view lists the semi-private groups created using Directory Manager in the connected identity store. It doesn't list expired or deleted semi-private groups. To view expired groups, see [View Expired Groups in Directory Manager](/docs/directorymanager/11.1/portal/group/allgroups/allexpiredgroups.md). To view deleted groups, see [Restore or Delete Groups in the Directory Manager Recycle Bin](/docs/directorymanager/11.1/portal/group/recyclebin/overview.md).

To search semi-private groups, [Modify Search Directory](allgroups.md#modify-search-directory). To narrow the list, click **Private Group Grid Filters** and add [Filter All Groups](allgroups.md#filter-all-groups). All the semi-private groups that match the filters appear.
