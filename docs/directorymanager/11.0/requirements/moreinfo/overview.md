# GroupID Service Account Permissions

To connect an Active Directory identity store to a domain, you must use a service account with
elevated privileges. You can also use a Group Managed Service Account (gMSA) for this purpose.

See the following topics for details on these accounts:

- [Set Up a GroupID Service Account for AD and Exchange](/docs/directorymanager/11.0/requirements/moreinfo/adserviceaccount.md)
- [Configure a gMSA for GroupID](/docs/directorymanager/11.0/requirements/moreinfo/gmsarequirements.md)
