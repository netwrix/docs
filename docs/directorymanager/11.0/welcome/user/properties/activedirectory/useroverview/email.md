# View Email Addresses and Subscriptions in GroupID

Use this tab to view the addresses assigned to this object.

**Addresses**

For a mail-enabled object, the messaging provider (such as Microsoft Exchange) assigns
different addresses to it for communication with different repositories (such as Address Book, SIP,
Outlook). This box displays these addresses.

**Subscriptions**

Displays the subscriptions assigned to the mailbox.

It also lists other subscriptions offered by Office 365 to a mailbox user. Select the checkbox for
a subscription to assign it to the mailbox.

The subscription list appears for mailbox objects when Office 365 is configured as the
messaging provider for the identity store.
