# Add or Edit GID Window

The Add or Edit GID window opens from a field where a Linux group is needed.

![addoreditgidwindow](/images/activitymonitor/9.0/admin/outputs/window/addoreditgidwindow.webp)

Enter the GID for the group you want in the textbox. Then click OK. The Add or Edit GID window closes,
and the group is added to the field where the window was opened.
