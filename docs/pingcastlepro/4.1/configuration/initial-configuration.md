# Initial configuration

After you install PingCastle Pro, set up scanning and report handling. Complete the tasks that apply to your environment.

## What's next

- **Scheduler** — Run scheduled scans from the PingCastle Pro server. See [Scheduler](./scheduler.md).
- **Agent deployment** — Push reports from domains that the scheduler can't reach, and import existing reports. See [Agent deployment](./agent-deployment.md).
- **Decryption keys** — Decrypt reports that agents encrypt before upload. See [Decryption keys](./decryption-keys.md).
