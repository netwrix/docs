# Manage your Directory Manager profile

To view and update your profile information in the directory, click your profile info in the top right corner and select **See full profile**.

The profile page has the same tabs as the user properties page. To manage your profile, see [Directory Manager User, Mailbox, and Contact Properties](/docs/directorymanager/11.1/portal/user/properties/overview.md).

## User profile validation

If profile validation applies to you, you must verify and update your profile information in the directory using the Directory Manager portal.

Profile validation isn't a one-time process. The administrator specifies a profile validation life cycle period (for example, 90 days), which means that you must validate your profile once during each 90-day cycle.

Your profile page displays your profile validation status next to your name. The status is one of the following:

- Verified User: your profile is validated.
- Verification Pending: you must validate your profile. Click **Validate Your Profile** on the toolbar. The Validate Profile Properties window opens, where you can validate your profile.
- Expired User: the user expired because they didn't validate their profile within the required duration. An expired user is disabled in the directory.
