# Members Page in the Create Group Wizard

You can add and remove members of the group. By default, you are a member of the
group.

- To add members, click **Add**. Enter a search string to locate the object to add as a group
  member, or click **Advance** to use the
  [Find Users, Groups, and Contacts in GroupID](/docs/directorymanager/11.0/welcome/generalfeatures/find.md) to perform a
  search.

    The selected members are listed in the grid on the **Members** page.

- You can also add members to the group by using an external file, or import all members of one or
  more existing groups into this group.

    Click **Import** to launch the **Import Members** wizard. See
    [Import group members in GroupID](/docs/directorymanager/11.0/welcome/group/properties/importmembers.md)
    for information.

- To remove an object from the members list, select it and click **Remove**.

The Membership Life Cycle job updates the temporary membership of groups. It adds and removes
temporary members from group membership on the specified dates.

Consider a scenario where the Membership Life Cycle job is scheduled to run once a week, for
example on Mondays. If an object is to be added to group membership for three days, Wednesday
through Friday, it isn't added. This happens because the Membership Life Cycle job doesn't run on
those days to update temporary membership.

After adding members, click **Next**.
