# SAML Configuration for Directory Manager Using PingOne

PingOne is an Identity as a Service (IDaaS) solution that enables organizations to deliver single
sign-on with just one username and password.

To configure single sign-on in Directory Manager using PingOne as a provider, follow these steps:

- Generate the consumer URL and Directory Manager metadata file for the Directory Manager client
  with which you want to configure PingOne.
- Configure Directory Manager in PingOne.
- Configure the PingOne provider in Directory Manager.

After you complete these steps, you can sign in to Directory Manager using PingOne.
