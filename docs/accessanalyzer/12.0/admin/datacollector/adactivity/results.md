# ADActivity: Results

Use the Results page to select the properties to gather. This wizard page appears for all
categories.

![Active Directory Activity DC wizard Results page](/images/accessanalyzer/12.0/admin/datacollector/adactivity/results.webp)

Select properties individually, or use the **Select All** and **Clear All** buttons. The data
collector gathers all selected properties. Available properties vary based on the category you
select.
