# Mailbox Properties Auto Reply Tab in Directory Manager

Use this tab to configure automatic replies for the emails sent to a mailbox object. You can:

- Enable or disable automatic replies to senders from your organization.
- Enable or disable automatic replies to senders from other organizations.
- Compose the message to send as the automatic reply. You can write different messages for senders from
  your organization and for senders from other organizations.
- Specify the time period during which to send automatic replies.

**Don't send automatic replies**

Select this option button to disable the out-of-office replies feature.

**Send automatic replies**

Select this option button to send out-of-office replies to senders.

**Send replies only during this time period**

Select this checkbox to specify a time frame during which to send the automatic replies.

**Start Time, End Time**

Specify the date and time between which to send the replies.

**Send reply once to each sender inside my organization with the following message**

In the text box, enter the content to send as the reply to senders from your organization.

**Send automatic reply messages to senders outside my organization**

Select this checkbox to send automatic replies to senders from other organizations as well.

**Send replies only to senders in my contact list**

Select this option button to send replies only to external senders who are on your contact list.

**Send replies to all external senders**

Select this option button to send replies to all external senders.

**Send a reply once to each sender outside my organization with the following message**

In the text box, enter the content to send as the reply to senders who don't belong to your organization.
