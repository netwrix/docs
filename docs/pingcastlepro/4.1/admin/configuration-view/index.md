# Configuration view

The **Configuration** view of PingCastle Pro lets you set up the tool and personalize settings so it better fits your company's needs. It covers:

- [Exceptions](exceptions.md) — Disable rules for a domain, or apply exceptions while a domain migrates.
- [Importing reports](importing-reports.md) — Add PingCastle reports to PingCastle Pro manually or through an agent.
