# SMARTLog: Target Log for Windows Event Log Type

Use the Target Log page to select the logs to collect. This version is a wizard page for
the log type of Windows Event Log.

![SMART Log DC Wizard Target Log page for Windows Event Log](/images/accessanalyzer/11.6/admin/datacollector/smartlog/targetlogtype/targetlogwindowsevent.webp)

You can target only one log per query task. The selected log displays at the bottom of the
wizard page.
