# Tags Node

You can add tags to templates as an organizational tool. Tags display as folders under the
TAGS node. Several preconfigured templates include tags, which display after you import those
templates into the Administration Console. A template can have multiple tags, and the
template displays in the folder for each tag. If you add a new tag, refresh the TAGS node to
view its folder.

![Tags node](/images/threatprevention/8.1/admin/tags/tags.webp)

Adding tags to a template creates multiple places to access the template from rather than a
duplicate template. When you modify a template within a folder under the TAGS node, the change
applies to that template wherever you access it afterward, whether from under the
Templates node or from another folder under the TAGS node.
