# Navigate the Directory Manager SSPR Portal

When you sign in to the self-service password reset (SSPR) portal, you land on the main portal page. It displays all the functions the portal supports.

## Top right options

The top right corner of the application displays the following icons.

### Help icon

Click the Help icon to launch the help pages for the SSPR portal.

### Profile icon

The Profile icon displays your profile picture with your name and the identity store the portal is connected to. Click it to open a menu that displays the Directory Manager version and the security role assigned to you in Directory Manager. The menu also displays the following options:

- My Applications – Opens the Directory Manager Applications page, which displays the Directory Manager clients that you have access to. See the [Access Your Applications in Directory Manager](/docs/directorymanager/11.1/admincenter/general/accessapplications.md) topic for additional information.
- Enroll your account – Opens the Your Enrollments page, where you can enroll the identity store account you used to sign in to the portal. Tabs on this page represent the different authentication types the administrator has enabled for enrollment. See the [Enroll Your Account in Directory Manager](/docs/directorymanager/11.1/admincenter/general/enroll.md) topic for enrollment details, starting at step 3.
- Change password – Use this to change your identity store account password. See the [Change Your Password in Directory Manager](/docs/directorymanager/11.1/portal/user/manage/changepassword.md) topic for additional information.
- Switch Account – Use this to access the portal with a different account. See the [Switch Accounts in Directory Manager](/docs/directorymanager/11.1/admincenter/general/switchaccount.md) topic for additional information.
- Sign Out – Click it to sign out of the SSPR portal.

## Portal functions

The main portal page displays three tiles:

- Enroll
- Change Password
- Linked Accounts

See the [Manage Your Identity Store Accounts in the SSPR Portal](/docs/directorymanager/11.1/ssprportal/functions.md) topic for a discussion of these functions.
