# Security

On this step, restrict access to the administrative web console by adding users.

![initial_config_users](/images/dataclassification/5.6.2/deployment/initial_config_users.webp)

- Enable user management – select to add super users and prevent unauthorized access to
  administrative web console. By default, any authenticated users have access to the console.

    **NOTE:** Netwrix recommends enabling this option.

    When selected, add super users. Enter the name of the new user and click + on
    the right.

- Allow access for all users – select to allow any user access to the administrative web console.
