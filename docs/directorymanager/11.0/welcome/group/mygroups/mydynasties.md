# View My Dynasties in GroupID

This page lists the Dynasties you are the primary owner of. To include the groups for which you are
an additional owner, select the **Display additional group ownership in My Dynasties** checkbox on
the [Configure GroupID Portal Settings](/docs/directorymanager/11.0/welcome/generalfeatures/portal.md) panel.

You can
[Modify Search Directory](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#modify-search-directory)
to search Dynasties and add
[Filter All Groups](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#filter-all-groups)
by clicking **My Dynasties Grid Filters**. All the Dynasties matching the filters appear.
