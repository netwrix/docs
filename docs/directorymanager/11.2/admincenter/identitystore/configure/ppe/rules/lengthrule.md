# Configure the Length Rule in Directory Manager

The Length rule rejects passwords that contain too few or too many characters. Longer passwords are generally stronger. Set a maximum password length only if you must keep compatibility with a system that can't accept long passwords.

To configure the Length rule:

1. Enable the **Length** button.
2. Select one of the following options:

    - At least `number of` characters: Sets the minimum number of characters that passwords must contain. Choose the number from the dropdown list.
    - No more than `number of` characters: Sets the maximum number of characters that passwords can contain. Choose the number from the dropdown list.
    - Between `number` of `number` characters: Sets the minimum and maximum number of characters that passwords can contain. Choose the minimum from the first dropdown list and the maximum from the second.
