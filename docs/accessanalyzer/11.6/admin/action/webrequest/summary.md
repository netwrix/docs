# Web Request: Summary

The Summary page displays a summary of the configured action.

![Web Request Action Module Wizard Summary page](/images/accessanalyzer/11.6/admin/action/webrequest/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the Web Request Action Module Wizard without saving accidental clicks.
