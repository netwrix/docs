# About PingCastle Enterprise

This documentation covers PingCastle Enterprise 4.0, the web-based edition of PingCastle that adds a scheduler service, agents, an API, and centralized reporting. Netwrix also offers PingCastle Pro and PingCastle Community. See [PingCastle Pro](/docs/pingcastlepro/4_0/) and [PingCastle Community](/docs/pingcastlecommunity/4_0/) for those editions.

## About PingCastle

PingCastle is a security assessment and auditing tool for CISOs, security auditors, and IT professionals working with Active Directory and Entra ID.

Netwrix offers various products to help protect your network infrastructure. PingCastle focuses specifically on assessment. It collects comprehensive information from your Active Directory and Entra ID environments, analyzes this data for security risks and misconfigurations, and generates detailed reports with actionable findings.

These reports help you identify and prioritize security issues that need remediation, giving you clear visibility into your security posture and enabling data-driven decisions to improve your environment's security.

## Methodology

The PingCastle tool is one part of a global methodology for securing Active Directory.

For details on how the tool fits into the broader process of securing Active Directory, see the [PingCastle methodology page](https://www.pingcastle.com/methodology/).

All PingCastle editions share the `PingCastle.exe` command-line tool. PingCastle Enterprise agents run `PingCastle.exe` to collect data and send reports to the server. The PingCastle.exe documentation is maintained once, in the PingCastle Community documentation:
