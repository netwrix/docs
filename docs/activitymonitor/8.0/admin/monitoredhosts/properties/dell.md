# Dell Tab

The Dell tab on a host’s Properties window displays the Dell Celerra/VNX, Dell Isilon/PowerScale,
Dell PowerStore, or Dell Unity host to monitor for activity and any host aliases. This tab populates with the information you enter when adding the Dell host to the monitored hosts table. If
desired, specify a different device to monitor for activity.

![Dell Tab](/images/activitymonitor/8.0/admin/monitoredhosts/properties/emctabemcvnxcelerra.webp)

If changes are made to these configuration options, click **OK** to save the changes.
