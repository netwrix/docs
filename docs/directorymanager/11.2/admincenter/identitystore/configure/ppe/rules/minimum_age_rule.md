# Configure the Age (Min) Rule in Directory Manager

The Minimum Age rule stops users from quickly cycling through a series of passwords to evade the History and Similarity rules. Only domain policies can enforce this rule.

To configure the Age (Min) rule:

1. Enable the **Age (Min)** button.
2. Select the number of days before a user can change their password.

:::note
The Minimum Age rule is unique because users can't comply with it by choosing a different password. They must wait until the required number of days has elapsed.
:::
