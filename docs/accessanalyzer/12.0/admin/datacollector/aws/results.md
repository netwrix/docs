# AWS: Results

Use the Results page to select the properties to gather. It is a wizard page for all of the
categories.

![Results page](/images/accessanalyzer/12.0/admin/datacollector/aws/results.webp)

You can check properties individually, or use the **Select All** or **Clear All** buttons. The
wizard gathers all checked properties. Available properties vary based on the category selected.
