# File System Action: Summary

The Summary page displays a summary of the configured action.

![File System Action Module Wizard Summary page](/images/accessanalyzer/11.6/admin/action/filesystem/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the File System Action Module Wizard without saving accidental clicks.
