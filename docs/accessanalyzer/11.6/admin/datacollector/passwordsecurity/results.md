# PasswordSecurity: Results

Use the Results page to select the Active Directory properties to gather.

![Password Security Data Collection Wizard Results page](/images/accessanalyzer/11.6/admin/datacollector/passwordsecurity/results.webp)

Select properties individually, or use the **Select All** or **Clear All** buttons. Enterprise
Auditor gathers all selected properties.
