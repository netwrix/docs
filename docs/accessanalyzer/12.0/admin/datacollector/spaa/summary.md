# SPAA: Summary Page

The Summary page summarizes the configuration settings. It's a wizard page for all of the
categories.

**-![Summary Page](/images/accessanalyzer/12.0/admin/datacollector/spaa/summarypage.webp)**

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the SharePoint Access Auditor Data Collector Wizard without saving accidental clicks.
