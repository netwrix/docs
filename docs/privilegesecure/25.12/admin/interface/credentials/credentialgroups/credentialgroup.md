# Add Credential Groups

To add credential groups to the Privilege Secure Console.

1. Navigate to the **Policy** > **Credentials** > **Credential Groups** page.
2. In the Credential Groups list, click the **Plus** icon.

   ![Add credential group](/images/privilegesecure/25.12/accessmanagement/admin/policy/add/addcredentialgroup.webp)

3. Enter or select the following information:

   - **Name** — Displays the name of the credential
   - **Description** — Description of the policy

4. Click **Save** to create the new credential group.

   ![Credential Group add credentials button](/images/privilegesecure/25.12/accessmanagement/admin/policy/add/addcredentialstogroup.webp)

5. With the new credential group selected, click the **+ Add Credentials** button to open
   the **Add Credentials** window.

   ![Add Credentials window listing available credentials](/images/privilegesecure/25.12/accessmanagement/admin/policy/add/addcredentials.webp)

6. Select the checkbox for the credential and click **Add** to save the credential to the
   Credential Group. See the
   [Add Credentials to a Credential Group](/docs/privilegesecure/25.12/admin/interface/credentials/credentialgroups/addcredentials.md#add-credentials-to-a-credential-group)
   topic for additional information.

The new credential group is added to the console and is shown in the Credential Groups list.
