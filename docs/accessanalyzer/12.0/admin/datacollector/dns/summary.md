# DNS: Summary

The Summary page summarizes the configured query. It's a wizard page for all categories.

![Domain Name System Data Collector Wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/dns/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel** to
close the Domain Name System Data Collector Wizard instead, so accidental clicks don't get saved.
