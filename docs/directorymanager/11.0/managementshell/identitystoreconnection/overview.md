# Identity Store Connection Cmdlets in GroupID

This section covers cmdlets for establishing a connection with an identity store.

- [Connect-IdentityStore Cmdlet in GroupID](/docs/directorymanager/11.0/managementshell/identitystoreconnection/connectidentitystore.md):
  Connects to an identity store using the authentication mode specified.
- [Get-Token Cmdlet in GroupID](/docs/directorymanager/11.0/managementshell/identitystoreconnection/gettoken.md):
  Gets a token from the GroupID Security Service.
