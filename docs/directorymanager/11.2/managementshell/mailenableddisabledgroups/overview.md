# Directory Manager Mail-Enable and Mail-Disable Group Cmdlets

These cmdlets enable and disable groups for email.

- [Disable-DistributionGroup Cmdlet in Directory Manager](/docs/directorymanager/11.2/managementshell/mailenableddisabledgroups/disabledistributiongroup.md) – disables a group's email capability.
- [Enable-DistributionGroup Cmdlet in Directory Manager](/docs/directorymanager/11.2/managementshell/mailenableddisabledgroups/enabledistributiongroup.md) – enables a group's email capability.
