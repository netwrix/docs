# ADPermissions: Summary

The Summary page summarizes the configuration settings. It is a wizard page for all of the
categories.

![ADPermissions Data Collector wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/adpermissions/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel** to
close the Active Directory Permissions Data Collector Wizard. This ensures the wizard doesn't save
accidental clicks.
