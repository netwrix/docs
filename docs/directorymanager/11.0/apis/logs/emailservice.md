# Download Email Service Logs with the API

Use this API to get Directory Manager Email Service logs. See the
[Directory Manager Email Service](/docs/directorymanager/11.0/signin/service/emailservice.md) topic for
additional information on the Email Service.

## Endpoint

https://demomachine:4443/GroupIDEmailService/api/Logs/Download

## HTTP Method

GET

### Sample Response Syntax

```
<Encrypted response>
```

Save the encrypted response as a zip file to a desired location.
