# Public Folder: Summary

The Summary page summarizes the configuration of the action.

![Public Folder Action Module Wizard Summary page](/images/accessanalyzer/12.0/admin/action/publicfolder/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel** to
close the Public Folder Action Module Wizard instead. This prevents the wizard from saving
accidental clicks.
