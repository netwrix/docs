# ExchangePS: Results

The Results page is where you select the properties to gather. It is a wizard page for all
of the categories.

![ExchangePS Data Collector Wizard Results page](/images/accessanalyzer/12.0/admin/datacollector/exchangeps/results.webp)

You can select properties individually, or use the **Select All** and **Clear All** buttons.
The data collector gathers all selected properties. Available properties vary based on the category selected.
