# Remove Server from List

The Agents Interface displays a list of servers where the Agent is deployed. You may want to
remove a server from this list for any reason, such as when you no longer need the Agent on the
server.

:::note
If the server has a deployed Agent, the Agent will be added back to the list the next time it
sends information to the Enterprise Manager.
:::

**Step 1 –** Click Agents in the left pane to launch the Agents interface.

**Step 2 –** Right-click a server and select **Remove Server from List** on the menu.

The server is removed from the list.
