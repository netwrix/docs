# NIS: Results

Use the Results page to select properties from Unix to gather. It is a wizard page for both
categories.

![NIS Data Collector Wizard Results page](/images/accessanalyzer/12.0/admin/datacollector/nis/results.webp)

Select available properties' checkboxes individually, or use the **Select All**, **Clear All**, and
**Reset to defaults** buttons. Access Analyzer gathers all selected properties. Available properties
vary based on the category selected.

This information isn't available within the standard reference tables and views. Instead, you can
view this information in the `SA_[Job Name]_DEFAULT` table, which is created when you select any of
these properties.
