# Identity Store Connection Cmdlets in Directory Manager

This section covers cmdlets for establishing a connection with an identity store.

- [Connect-IdentityStore Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/identitystoreconnection/connectidentitystore.md):
  Connects to an identity store using the authentication mode specified.
- [Get-Token Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/identitystoreconnection/gettoken.md):
  Gets a token from the GroupID Security Service.
