# Related

Use the Related tab to view and modify the non-hierarchical relationships between preferred
terms. This tab appears only if the taxonomy is in SQL, as the SharePoint Term Store doesn't
support this functionality.

![relatedtermstab](/images/dataclassification/5.8/admin/taxonomies/relatedtermstab.webp)

When a term appears in multiple branches of the taxonomy (a polyhierarchical taxonomy), the
Related tab also displays each of the locations so you can jump to the specific branch.
