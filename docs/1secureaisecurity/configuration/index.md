# Configuration

The first run takes you from no sources to your first scan. You pick where agents could be running, connect those platforms, add any permissions they still need, and start the scan. Check the [Requirements](/docs/1secureaisecurity/requirements/index.md) first.

## Run your first scan

1. [The Get started page](/docs/1secureaisecurity/configuration/the-get-started-page.md)
2. [Choose where to look](/docs/1secureaisecurity/configuration/choose-where-to-look.md)
3. [Connect with Microsoft](/docs/1secureaisecurity/configuration/connect-with-microsoft.md)
4. [Add additional permissions](/docs/1secureaisecurity/configuration/add-additional-permissions.md)
5. [Run your first scan](/docs/1secureaisecurity/configuration/run-your-first-scan.md)

[What happens when you connect Microsoft](/docs/1secureaisecurity/configuration/what-happens-when-you-connect-microsoft.md) explains the two Microsoft windows and what 1Secure keeps and drops.

## Connect other sources

[Sources](/docs/1secureaisecurity/configuration/sources/index.md) has a page for each platform. It says what the connector reads, what to create in the vendor's console, and what each test result means.

## Reference and removal

- [Reference](/docs/1secureaisecurity/configuration/reference.md) lists the permissions each source asks for and the data AI Security keeps.
- [Remove AI Security from your Microsoft tenant](/docs/1secureaisecurity/configuration/remove-ai-security-from-your-microsoft-tenant.md) removes the Netwrix application, its permissions, and its roles.
