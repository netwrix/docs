# Smart Group Cmdlets in Directory Manager

This section covers cmdlets for managing Smart Groups.

- [ConvertTo-StaticGroup Cmdlet](/docs/directorymanager/11.1/managementshell/smartgroup/converttostaticgroup.md) – Converts a Smart Group or a Dynasty to a static
  group.
- [Get-SmartGroup Cmdlet](/docs/directorymanager/11.1/managementshell/smartgroup/getsmartgroup.md) – Retrieves Smart Groups and Dynasties that match the given
  criteria.
- [New-SmartGroup Cmdlet](/docs/directorymanager/11.1/managementshell/smartgroup/newsmartgroup.md) – Creates a new Smart Group (managed group) in the directory.
- [Set-SmartGroup Cmdlet](/docs/directorymanager/11.1/managementshell/smartgroup/setsmartgroup.md) – Modifies a Smart Group in the directory.
- [Update-Group Cmdlet](/docs/directorymanager/11.1/managementshell/smartgroup/updategroup.md) – Modifies the membership of a Smart Group or Dynasty according to
  the results returned by the LDAP query.
- [Upgrade-Group Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/smartgroup/upgradegroup.md) – Upgrades managed (Smart Groups and Dynasties) and non-managed
  groups from Directory Manager 9 and 10 to Directory Manager 11.
