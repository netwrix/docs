# CLU: Summary

The Summary page summarizes the query you created or edited. It's a wizard page for all profile
types.

![Command Line Utility Data Collector Wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/commandlineutility/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel** to
close the Command Line Utility Data Collector Wizard instead, so accidental clicks don't get saved.
