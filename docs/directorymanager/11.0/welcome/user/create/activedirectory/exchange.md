# Exchange page in the Create Mailbox wizard

Use this page to provide the alias and subscriptions for a mailbox.

1. In the **Alias** box, enter an alias for the mailbox.
2. In the **Mailbox Store** list, select a mailbox store to create the user's mailbox on.
3. The **Subscription List** provides the subscriptions offered by Office 365 to a mailbox user.
   Select the checkboxes for the subscriptions you want to assign to this mailbox.

    The subscription list appears when Office 365 is configured as the messaging provider for
    the identity store.

4. Click **Next**.
