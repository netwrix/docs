# API reference

This reference documents the endpoints of the Netwrix Privilege Secure for Access Management (Privilege Secure) REST API for release 26.07.3. It is generated from the product's OpenAPI 3.0 specification. Every operation that the console performs goes through this API.

Each endpoint page lists the HTTP method and path, the parameters, the request body, the responses, and the sign-in requirement. For how to address the API and get a token, see [REST API overview](/docs/privilegesecure/26.07/integrations/api/api-overview.md) and [Authenticate to the API](/docs/privilegesecure/26.07/integrations/api/api-authentication.md).

Endpoints are grouped by the area of the product that they manage, such as access policies, activities, credentials, and sessions.

To download the specification, use [privilegesecure-26.07.json](/openapi/privilegesecure-26.07.json).
