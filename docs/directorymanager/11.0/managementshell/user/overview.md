# User Cmdlets in Directory Manager

This section covers cmdlets for performing user-related tasks such as the following:

- [Get-User Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/user/getuser.md): retrieves a
  user.
- [Get-UserEnrollment Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/user/getuserenrollment.md):
  displays information about the status of user enrollment.
- [New-User Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/user/newuser.md): creates a
  user.
- [Remove-User Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/user/removeuser.md): removes a
  user from the directory.
- [Set-User Cmdlet for Directory Manager ](/docs/directorymanager/11.0/managementshell/user/setuser.md): modifies a user
  in the directory.
