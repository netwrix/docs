# User Lifecycle Cmdlets for GroupID

This section covers the cmdlets for performing user lifecycle tasks, such as:

- [Extend-User Cmdlet for GroupID](/docs/directorymanager/11.0/managementshell/userlifecycle/extenduser.md):
  Activates a user account for a specific number of days.
- [Get-Status Cmdlet for GroupID](/docs/directorymanager/11.0/managementshell/userlifecycle/getstatus.md):
  Provides the status of a user according to the profile validation criteria.
- [Reinstate-User Cmdlet for GroupID](/docs/directorymanager/11.0/managementshell/userlifecycle/reinstateuser.md):
  Activates or disables a user.
- [Terminate-DirectReports Cmdlet for GroupID](/docs/directorymanager/11.0/managementshell/userlifecycle/terminatedirectreports.md):
  Terminates direct reports of a user.
- [Transfer-DirectReports Cmdlet ](/docs/directorymanager/11.0/managementshell/userlifecycle/transferdirectreports.md):
  Transfers direct reports of a user.
