# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Product

**Netwrix Identity Recovery** backs up and restores identity infrastructure. Administrators roll back or recover Active Directory, Microsoft Entra ID, and Okta objects (or single attributes) to a known good state, and restore a domain controller or an entire Active Directory forest from a point-in-time backup. An RSAT extension exposes the same rollback and recovery operations inside Active Directory Users and Computers.

The product was formerly named **Recovery for Active Directory** (documented as version 2.6 under `docs/recoveryforactivedirectory/`). Use "Netwrix Identity Recovery" on first reference, "Identity Recovery" thereafter.

## Versions

Documented version: **3.1** (latest). The sidebar is autogenerated from the folders (`sidebars/identityrecovery/3.1.js`), so a new page needs no sidebar edit. Order comes from `_category_.json` `position` values and page `sidebar_position` frontmatter; keep a category's position equal to its linked overview page's `sidebar_position`.

### Configuration vs Administration

Entra ID, Okta, and Forest each appear twice: `configuration/<name>.md` connects the product to the directory or adds the forest, and `admin/<name>/` is where you configure backups and recover and roll back objects. The Configuration pages are titled "Connect Entra ID", "Connect Okta", and "Connect a Forest" so the two read differently in the sidebar, search results, and breadcrumbs. Keep that distinction when adding pages.

### Redirects

Pages moved during the zone reorganization are redirected in `src/config/redirects/identityrecovery-3.1.js`. If you move or rename a page, add its old path there.

## KB Articles

KB articles are not stored in the version folder. `scripts/copy-kb-to-versions.mjs` copies `docs/kb/recoveryad/` into `docs/identityrecovery/3.1/kb/` at build time, and that folder is gitignored. Edit KB articles in `docs/kb/recoveryad/` only.

## Images

Product images are in `static/images/identityrecovery/3.1/`. Reference them with absolute paths, for example:

```
/images/identityrecovery/3.1/product/configuration/licensing_configuration.png
```

Moving a page does not affect its images.

## Links

Internal links use absolute paths with the `.md` extension, for example `/docs/identityrecovery/3.1/configuration/domain.md`. The build fails on broken markdown links and anchors, so run `DOCS_PRODUCT=identityrecovery DOCS_PRODUCT_LATEST_ONLY=true npm run build` after moving pages.
