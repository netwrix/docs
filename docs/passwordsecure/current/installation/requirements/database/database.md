# Database server

Netwrix Password Secure supports the following database servers:

- [Microsoft SQL Server (MSSQL)](mssql_server.md)
- [Azure SQL](azure_sql.md)
- [PostgreSQL](postgresql.md)

Each database server has its own version, configuration, and networking requirements. Review the requirements for the database server you plan to use before you install Netwrix Password Secure.
