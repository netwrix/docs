# Administration

This document provides a comprehensive resource for system administrators tasked with managing
Netwrix Endpoint Protector. It offers in-depth information on the system's components,
functionality, and best practices.

Endpoint Protector is a complex system composed of interconnected elements: endpoint clients,
supported devices, user accounts, and a central server infrastructure. This document will guide you
through understanding these components and their roles within the system.

Gain insights into managing users, devices, and network policies to ensure optimal system
performance and data security.

## Where to find what

Start with [Configuration](/docs/endpointprotector/configuration/configuration.md) for the one-time setup after installation. This section covers the console login, dashboard, alerts, reports, System Parameters, System Configuration, and System Maintenance.

The feature areas are in the sections under Configuration:

- [Device Control](/docs/endpointprotector/configuration/dc_module/dcmodule.md)
- [Content Aware Protection](/docs/endpointprotector/configuration/cap_module/capmodule.md)
- [Denylists and Allowlists](/docs/endpointprotector/configuration/denylistsallowlists/overview.md)
- [eDiscovery](/docs/endpointprotector/configuration/ed_module/edmodule.md)
- [Enforced Encryption](/docs/endpointprotector/configuration/ee_module/eemodule.md)
- [EPP Client](/docs/endpointprotector/configuration/eppclients/agent.md)

To connect Endpoint Protector to other systems, see [Integrations and API](/docs/endpointprotector/integrations/overview.md).
