# Mailbox Properties Limits Tab in Directory Manager

This tab applies to mailboxes only. Use it to set the storage quota for the object's mailbox,
such as an Exchange mailbox.

**Use default storage quota**

Select this checkbox to use the default quota for the mailbox store instead of defining it
individually.

**Issue warning (K)**

The mailbox size in kilobytes (KB) for this user. When the mailbox exceeds it, Directory Manager triggers an over-limit warning. The user can still send and receive messages.

**Prohibit Send (K)**

The maximum mailbox size in kilobytes (KB) for this user. When the mailbox exceeds it, the user can't send emails.

**Prohibit Send/Receive (K)**

The maximum mailbox size in kilobytes (KB) for this user. When the mailbox exceeds it, the user can't send or receive emails.
