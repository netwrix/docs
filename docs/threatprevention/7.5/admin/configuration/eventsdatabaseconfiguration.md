# Events Database Configuration Window

The Events Database Configuration window manages the Events database (NVMonitorData). Click **Configuration** > **Database** > **Server** on the menu to open it.

Only Threat Prevention administrators can access this window.

![Events Database Configuration Window](/images/threatprevention/7.5/admin/configuration/eventsdatabaseconfig.webp)

The Threat Prevention Enterprise Manager installation initializes the Event database. See the [Application Server Install](/docs/threatprevention/7.5/install/application.md) topic for additional information. This window displays the current connection settings for the Event database.

Use the DB Connection Manager application to change credentials and/or SQL Server host information. See the [DB Connection Manager Wizard](/docs/threatprevention/7.5/install/dbconnectionmanager.md) topic for additional information.
