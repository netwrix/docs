title: Configuration
description: Set up what Access Analyzer scans and how it signs in, from sources and service accounts to agents, sensitive data patterns, and settings.
---

Configuration is the setup that scans depend on: the sources Access Analyzer reads, the service accounts it signs in with, the agents that run scans, the sensitive data patterns that Sensitive data scans match, and the settings that apply to the whole installation. [Administration](../admin/index.md) covers scans themselves, because running and following scans is day-to-day work.
