# Create Active Directory user objects in Directory Manager

In an Active Directory identity store, you can create the following types of users:

- User – See the [Create an AD User in Directory Manager](/docs/directorymanager/11.1/portal/user/create/AD/user.md) topic for additional information.
- Mailbox – See the [Create an Active Directory mailbox in Directory Manager](/docs/directorymanager/11.1/portal/user/create/AD/mailbox.md) topic for additional information.
- Contact – See the [Create an Active Directory contact in Directory Manager](/docs/directorymanager/11.1/portal/user/create/AD/contact.md) topic for additional information.
