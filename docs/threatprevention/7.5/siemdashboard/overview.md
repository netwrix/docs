# SIEM Dashboards

Threat Prevention (formerly StealthINTERCEPT) integrates with any SIEM dashboard your company uses. Netwrix provides custom apps for integration with three specific dashboards:

- IBM QRadar Integration
- Splunk Integration - Active Directory
- Splunk Integration - Threat Hunting

You can also use the [SIEM Output Viewer](/docs/threatprevention/7.5/admin/configuration/siemoutputviewer.md) to view the data Threat Prevention sends to syslog (SIEM).
