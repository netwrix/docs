# ADPermissions: Summary

The Summary page summarizes the configuration settings. It is a wizard page for all of the
categories.

![ADPermissions Data Collector wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/adpermissions/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** to close
the Active Directory Permissions Data Collector Wizard and avoid saving accidental clicks.
