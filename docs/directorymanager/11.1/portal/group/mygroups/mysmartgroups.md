# View Your Smart Groups in Directory Manager

This page lists only the Smart Groups that you are the primary owner of.

To include the groups that you co-own, select the **Display additional group ownership in My Smart Groups** checkbox on the [Configure Directory Manager Portal Settings](/docs/directorymanager/11.1/portal/generalfeatures/portal.md) panel. You are an additional owner of those groups.

To search your Smart Groups, [Modify Search Directory](/docs/directorymanager/11.1/portal/group/allgroups/allgroups.md#modify-search-directory). To narrow the list, click **Smart Group Grid Filters** and add [Filter All Groups](/docs/directorymanager/11.1/portal/group/allgroups/allgroups.md#filter-all-groups). All the Smart Groups that match the filters appear.
