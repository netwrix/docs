# Synchronize Dashboard in Directory Manager

The Synchronize dashboard shows your jobs and job collections and gives you quick access to search, background job status, and the Synchronize menu. After you sign in to the Directory Manager portal, select **Synchronize** in the left pane to open the dashboard.

![Synchronize dashboard in the Directory Manager portal showing the menu pane and job cards](/images/directorymanager/11.1/portal/synchronize/synchronizedashboard.webp)

The dashboard has four areas:

- Quick search
- Top right options
- Menu pane
- Dashboard cards

## Quick search

Use **Search** at the top of the page to find jobs and job templates and view their information.

## Top right options

The top right corner of the application shows these icons:

| Icon                 | Description                                                                                                                                                                                                                                                                                                                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Background jobs icon | View the status of jobs and job collections that are running in the background. It displays: <ul><li>Jobs</li><li>Completed Jobs: Jobs that have been completed.</li><li>In Progress Jobs: Jobs that are still running.</li><li>Job Collections</li><li>Completed Jobs: Job collections that have been completed.</li><li>In Progress Jobs: Job collections that are still running.</li></ul> |
| Help icon            | Launch the Synchronize portal help.                                                                                                                                                                                                                                                                                                                                                                 |
| User profile icon    | Shows your profile picture, your name, and the identity store that the Directory Manager portal is connected to. Click it to open the menu, which includes the option to [Sign Out](/docs/directorymanager/11.1/portal/login.md#sign-out) of the portal.                                                                                                                                          |

## Dashboard cards

The dashboard has these cards:

| Cards                  | Description                                                 |
| ---------------------- | ----------------------------------------------------------- |
| Jobs For               | Displays the jobs based on their object types.              |
| Successful Jobs        | Displays the jobs that have been completed successfully.    |
| Jobs with Errors       | Displays the jobs that are completed with errors.           |
| Scheduled Jobs         | Displays jobs that run based on the time set for them.    |
| My Pinned Jobs         | Displays frequently used jobs.                              |
| Pinned Job Collections | Displays frequently used job collections.                   |
