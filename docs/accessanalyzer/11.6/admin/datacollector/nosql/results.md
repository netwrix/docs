# NoSQL: Results

Use the Results page to select the properties to gather. It is a wizard page for
all of the categories.

![NoSQL Data Collector Wizard Results page](/images/accessanalyzer/11.6/admin/datacollector/nosql/results.webp)

Select properties individually, or use the **Select All**, **Clear All**, and **Reset to
Defaults** buttons. The data collector gathers all selected properties. Available properties vary
based on the category selected.
