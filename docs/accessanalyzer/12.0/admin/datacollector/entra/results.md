# Entra: Results

Use the Results page to select the properties to gather from Microsoft Entra ID.

![Results page of the Entra Data Collector Wizard](/images/accessanalyzer/12.0/admin/datacollector/entra/results.webp)

Select properties individually, or use the **Select All** and **Clear All** buttons. The Entra data
collector collects all selected properties.
