# Notification: Summary

The Summary Page displays all the information input in each of the configured options from the
previous pages of the wizard.

![Notification Data Analysis Module wizard Summary page](/images/accessanalyzer/11.6/admin/analysis/notification/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the Notification Data Analysis Module wizard without saving accidental clicks.
