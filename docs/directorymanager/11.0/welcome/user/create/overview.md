# Create User, Mailbox, and Contact Objects

The GroupID portal lets you create the following types of users:

- User
- Mailbox
- Contact

GroupID supports the following identity providers for creating the user objects:

- Active Directory
- Microsoft Entra ID
- Generic LDAP
- Google Workspace
