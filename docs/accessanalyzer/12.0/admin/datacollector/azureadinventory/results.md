# AzureADInventory: Results

Use the Results page to select the Microsoft Entra ID properties to gather. It is
a wizard page for the Scan Entra ID category.

![Entra ID Inventory DC Wizard Results page](/images/accessanalyzer/12.0/admin/datacollector/azureadinventory/results.webp)

You can check properties individually, or use the **Select All** and **Clear All** buttons.
The data collector collects all checked properties. This information isn't available within the standard
reference tables and views. Instead, view this information in the
**SA_AzureADInventory_DEFAULT** table, which the data collector creates when you select any of these properties.
