# Configure Okta Single Sign-On for Directory Manager

Okta provides secure identity management and single sign-on to any application, whether in the
cloud, on-premises, or on a mobile device, for the employees of an organization.

To configure single sign-on in Directory Manager using Okta as the provider:

- Generate the consumer URL and audience URL for the Directory Manager client with which you want to
  configure Okta. See the [Generate Consumer and Audience URLs for Okta](/docs/directorymanager/11.2/authenticate/asserviceprovider/okta/generateurls.md) topic for more information.
- [Configure Directory Manager in Okta for SSO](/docs/directorymanager/11.2/authenticate/asserviceprovider/okta/configureinokta.md)
- [Configure Okta as a SAML Provider in Directory Manager](/docs/directorymanager/11.2/authenticate/asserviceprovider/okta/configureoktaindirectorymanager.md)

After that, you can sign in to Directory Manager using Okta. See the [Sign In to Directory Manager Using Okta](/docs/directorymanager/11.2/authenticate/asserviceprovider/okta/signin.md)
topic for more information.
