# EWSPublicFolder: Summary

The Summary page displays a summary of the configured query. It wizard page for all categories.

![EWS Public Folder Data Collector Wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/ewspublicfolder/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel**
instead to close the EWS Public Folder Data Collector Wizard without saving accidental clicks.
