# Password Manager

Use Password Manager to automatically schedule password changes for service accounts that access external systems. This is useful when your organization has rolling password policies.

![passwordmanager_thumb_0_0](/images/dataclassification/5.6.2/security/passwordmanager_thumb_0_0.webp)

To change a user's passwords, select **Passwords** from the main display. Then
click **Edit** on a password row to edit it, or click **Add Password** to add a new password for the
account. Don't create overlapping date ranges for passwords, and always keep at least one password per user record.
