# Administration

This configuration tab contains general options, as well as those that apply to taxonomies area and
to Concept Classifier app. By default, only basic options display. To view advanced options,
click the "wrench" icon at **Settings** in the bottom-right corner.

Most options have an associated information popup (the “**i**” symbol next to the option name) which describes what the setting does and how it works.

## Taxonomies

Use these settings to customize configuration of classification taxonomies.

| Option                                         | Description                                                                                                                                                                                                                                                                                           | Comment                                                                      |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **General settings**                           |                                                                                                                                                                                                                                                                                                       |                                                                              |
| Create Default Clues                           | Automatically create a Standard clue when you create a new term, using the term name as the clue text and default threshold value as the score.                                                                                                                                                               |                                                                              |
| User Term Suggestions                          | Enables/Disables a custom form designed to allow end-users to make suggestions on new terms for administrators.                                                                                                                                                                                       |                                                                              |
| User Term Suggestions Notification Email Group | Enables an automatic notification to a pre-configured email group when a term suggestion is created.                                                                                                                                                                                                  |                                                                              |
| **Advanced settings**                          |                                                                                                                                                                                                                                                                                                       |                                                                              |
| Synonyms Enabled                               | Controls whether you can configure synonyms (for each standard clue) for taxonomies residing in the local SQL database.                                                                                                                                                                         |                                                                              |
| Working Set Mode                               | Configures the Working Set functionality under 'Taxonomies'. Possible options: <ul><li>Use **Term Level** if you need a different working set for each class.</li><li>If you select **Taxonomy Level**, the same working set applies to all classes in the taxonomy.</li></ul> | Changing this option removes all documents from the current working set. |
| Taxonomy Default Page Size                     | Number of documents returned by default from Taxonomy Manager searches.                                                                                                                                                                                                                                                     |                                                                              |
| # Doc Metadata Fields Shown                    | Number of hint fields to show in Taxonomy Manager.                                                                                                                                                                                                                                                |                                                                              |
| Term User Locking Enabled                      | Enables/Disables the ability to "lock" terms when performing taxonomy management, preventing other users from editing the locked terms.                                                                                                                                                               |                                                                              |
| Enable Regex Browse Highlighting               | When enabled, the Browse UI highlights any matched regular expressions in search results (based on the selected terms clues).                                                                                                                                                   |                                                                              |
| Enable Page Info Regex Highlighting            | When enabled, the page info dialog highlights any matched regular expressions in the text.                                                                                                                                                                                             |                                                                              |
| Highlight Compound Term Parts                  | When using the Browse interface, the interface automatically highlights any detected clues in the document text. Enabling this mode highlights both the overall term (such as _'Triple heart bypass_') and the individual words (in this case: '_Triple_', '_heart_', and '_bypass_').  |                                                                              |
| Disable Doc Counts (Clues)                     | **Doc Counts** represents an untrimmed count of documents matching a particular clue or set of clues. This option disables/enables the selection of Doc Counts from the **Clues** edit screen.                                                                                                        |                                                                              |


## Concept Classifier App

Use these settings to customize configuration of Concept Classifier app.

| Option                                | Description                                                                                                                                                                                                                                                                                    | Comment                                                    |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| **General settings**                  |                                                                                                                                                                                                                                                                                                |                                                            |
| Enable Near Duplicate Detection       | The relevance threshold for duplicate detection matching (when using the Duplicates link from the SharePoint ribbon). When set to 100%, this option uses an exact match (matching checksum). When set to a lower threshold, the system attempts a fuzzy match to locate near duplicates. | Applies only to the deployment with the SharePoint add-in. |
| Duplicate Detection Scope             | Enables/disables scoping of duplicates detected via the SharePoint add-in interface. When disabled, the system identifies duplicates anywhere in the index. When enabled, the system scopes duplicates to their source group (or if no source group available <ul><li>to their source).</li></ul>     | Applies only to the deployment with the SharePoint add-in. |
| **Advanced settings**                 |                                                                                                                                                                                                                                                                                                |                                                            |
| Duplicate Detection Archive Indicator | Identifies documents within the View Duplicates display that are tagged with the archive indicator. You can optionally filter these identified documents from the display.                                                                                                                    |                                                            |
