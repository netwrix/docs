# Product Tour

New users now experience a product tour on first login. Standard users and users with the Privilege
Secure administrator role are walked through features that are relevant to their role.

![Product tour walkthrough shown on first login](/images/privilegesecure/26.03/accessmanagement/enduser/producttour.webp)

At any time, the tour can be stopped by clicking the **X** icon at the top-right of the Console. By
default, the tour will not display on next login unless the **don't display again** checkbox is
unchecked.

The product tour may be re-started at any time via the user menu.

![User menu in the Console](/images/privilegesecure/26.03/accessmanagement/enduser/usermenu.webp)

See the [Navigation](/docs/privilegesecure/26.03/admin/navigation/navigation.md) topic for additional information.
