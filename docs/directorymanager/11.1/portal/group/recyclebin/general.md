# Deleted Group General Tab in Directory Manager

Use this tab to view the general attributes of a deleted group, such as the group name, last known parent, creation date, and deletion date.

The tab displays the following attributes:

- Name
- Creation Date
- Common Name
- Object GUID
- Last Known Parent
- Deletion Date
- Distinguished Name
- Group Type
