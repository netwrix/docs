# WMICollector: Summary (Results)

The Summary page, or Results page, displays a summary of the configured query.

![WMI Browser wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/wmicollector/summary.webp)

Click **Finish** to save configuration changes. If you didn't make changes, it is a best practice to
click **Cancel** to close the WMI Browser wizard, which prevents the wizard from saving accidental
clicks.
