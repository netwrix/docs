# NIS: Summary

The Summary page summarizes the configuration settings. It is a wizard page for both categories.

![NIS Data Collector Wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/nis/summary.webp)

Click **Finish** to save configuration changes. If you didn't make changes, click **Cancel** to close
the NIS Data Collector Wizard and avoid saving accidental clicks.
