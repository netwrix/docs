# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Product

**Netwrix Data Classification** crawls data sources (file shares, SharePoint, Exchange, Box, Dropbox, Google Drive, SQL databases, and others), extracts and indexes document text, and classifies documents against built-in and user-defined taxonomies. Optional workflows act on classified documents, and classifications can be written back into Office and PDF files. A web console provides administration, search, and reports.

Use "Netwrix Data Classification" on first reference. "NDC" is common in the existing pages; match the page you are editing, and don't introduce "NDC" into a page that doesn't use it. Never use "Concept", the legacy product name.

## Versions

Documented versions: **5.6.2**, **5.7**, and **5.8** (latest). Edits to one version do **not** propagate to the others. Update each version the change applies to.

The sidebar is autogenerated from the folders (`sidebars/dataclassification/*.js`), so a new page needs no sidebar edit.

## Terminology

| Product or code term | Use in docs |
|---|---|
| QueryServer, QS | The Netwrix Data Classification web console |
| Class, Term | Class (the two are the same thing) |
| Clue | Clue (a match condition on a class: regex, phrase, metadata, date range, term boost) |
| Dynamic Source | A source that discovers sub-sources, such as a mailbox per Exchange user |
| MIP | Microsoft Information Protection sensitivity labels |

Don't document PostgreSQL or Oracle as supported Data Classification databases without confirming with the product team. The `postgresqlserver.md` page covers a PostgreSQL data source to scan, which is a different thing.
