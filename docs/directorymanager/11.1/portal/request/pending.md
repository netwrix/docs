# Manage Your Request Inbox in Directory Manager

Designated approvers use the Directory Manager portal to view workflow requests and approve or deny them.

## View requests

To view the requests that are waiting for approval:

1. On the left navigation bar, click **Requests**.
2. Click **Request Inbox**.

The request count appears next to the **Request Inbox** label.

By default, the page displays pending requests that were initiated today. You can also view processed (approved or denied) requests. Use filters to narrow the list of requests as needed.

For each request, you can view the description, approvers, requester name, the target to change, status of the request, creation date, and the reason the request was denied. Expand a request to view more details, such as the field changed along with its old and new values.

## Manage requests

You can perform the following functions on the **Request Inbox** page:

- [Approve a request](allrequest.md#approve-a-request).
- [Deny a request](allrequest.md#deny-a-request).
- [Filter requests](allrequest.md#filter-requests).
