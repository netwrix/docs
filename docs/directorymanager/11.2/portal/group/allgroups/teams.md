# View Microsoft Teams Groups in Directory Manager

This page lists all the Microsoft Teams groups.

To search teams, [Modify Search Directory](allgroups.md#modify-search-directory). To narrow the list, click **Teams Grid Filters** and add [Filter All Groups](allgroups.md#filter-all-groups). All the teams that match the filters appear.
