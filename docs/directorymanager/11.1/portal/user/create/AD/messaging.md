# Mail-enable a user on the Exchange page

Use this page of the Create User and Create Mailbox wizards to create the object as mail-enabled. A mail-enabled user is one with an email address.

:::note
To create a mail-enabled user, a messaging provider (such as Microsoft Exchange) must be
configured for the identity store.
If it isn't configured, the Messaging page is disabled.

:::

To mail-enable a user:

1. Ensure that the **Mail-Enabled** checkbox is selected to create the user as mail-enabled.

2. Review the alias that the **Alias** box displays for the user.

3. In the **Email Type** dropdown list, review the types of email you want to create. The list displays all of them.

4. In the **Email Address** box, enter an email address for the user. Directory Manager uses this email address to send email notifications to the user.

5. Click **Next**.
