# INIFile: Summary

The Summary page lists the selected configuration settings.

![INI File Data Collector Wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/inifile/summary.webp)

Click **Finish** to save configuration changes. If you didn't make changes, click **Cancel** to close
the INIFile Data Collector Wizard and avoid saving accidental clicks.
