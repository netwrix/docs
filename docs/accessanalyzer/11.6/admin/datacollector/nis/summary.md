# NIS: Summary

Use the Summary page to review a summary of the configuration settings. It is a wizard page for both
categories.

![NIS Data Collector Wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/nis/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel**
instead to close the NIS Data Collector Wizard without saving accidental clicks.
