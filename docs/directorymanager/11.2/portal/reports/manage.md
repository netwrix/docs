# Manage Directory Manager Reports

After you generate a report, the Reports list shows it under the template you used. The list displays the following for each report:

- Report name
- Category
- Created On
- Modified On
- Actions

You can run, edit, download, and delete reports from the Reports list.

## Run a report

Run a previously generated report to view its latest data.

1. In the Directory Manager portal, select **Reports** from the left pane.
2. On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose report you generated and click the template that you used. The template page lists the generated report.
3. Click the **Run arrow** icon next to the report. The report runs and appears on the page.

## Edit a report

When you generate a report, the Directory Manager portal saves the settings you provide. Launch the wizard again for a report to edit those settings.

1. In the Directory Manager portal, select **Reports** from the left pane.
2. On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose report you generated and click the template that you used. The template page lists the generated report.
3. Click the **Edit** icon next to the report.
4. Follow the wizard from **Step 1** of generating a report, as described in [Generate Reports in Directory Manager](/docs/directorymanager/11.2/portal/reports/generate.md), and make the changes you want.
5. Click **Finish** to generate the report.

## Download a report

You can also download a report from the Reports list.

1. In the Directory Manager portal, select **Reports** from the left pane.
2. On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose report you generated and click the template that you used. The template page lists the generated report.
3. Click the **Download** icon next to the report.
4. Select one of the following formats:

   - Excel
   - PDF
   - HTML

## Delete a report

When you delete a report, all its settings are removed.

1. In the Directory Manager portal, select **Reports** from the left pane.
2. On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose report you generated and click the template that you used. The template page lists the generated report.
3. Click the **Delete** button next to the report. The report is permanently deleted.
