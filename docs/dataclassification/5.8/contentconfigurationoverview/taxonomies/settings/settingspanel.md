# Taxonomy Settings Panel

The Taxonomy Settings panel displays the parameters of the top-level taxonomy selected in the Search
(for example, File Size).

![taxonomysettings](/images/dataclassification/5.8/admin/taxonomies/taxonomysettings.webp)

| Option                | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Content Filters       | This field lets you restrict the taxonomy based on a booleanfilter (e.g. using the “CSE-FOLDERS” field) or any of the 8 document id filters. See the associated design guide for more information about the ContentFilter field in the Taxonomies table. Valid entries include: <ul><li><booleanfilter>cse-folders= http://www.bbc.co.uk/sport/</booleanfilter>(only process documents from this path)</li><li><booleanfilter>NOT cse-folders=http://www.bbc.co.uk/sport/</booleanfilter> (exclude documents from this path)</li><li><booleanfilter>Author=Truman Capote</booleanfilter> (only process documents by this author)</li><li><documentidfilter>2</documentidfilter> (only process documents with this DocumentID value)</li><li><documentid4filter>3,77,890</documentid4filter> (only process documents with one of these DocumentID4 values) You can combine any number of entries by concatenation into a single string. The system ORs multiple restrictions of the same type together, so if multiple “cse-folders” entries exist then the document passes if it matches any one of them. The system ANDs multiple restrictions of different types together, so if multiple types exist then the document must pass all of them to get classified.</li></ul> |
| Max Categories        | Sets the maximum number of classes from this taxonomy that the product allocates to each document. To set the Max Categories value across all taxonomies use the Settings tab in Index Manager.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Default Threshold     | Sets the default threshold for newly created terms within the selected taxonomy (doesn't affect existing terms).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Create Default Clues  | This setting controls the creation of default clues. If enabled, the product adds a default clue to all Classes based on the title of the class – or, optionally based on the default metadata clue format.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Default Clue Score    | Sets the default score value for new clues.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Default Metadata Clue | Specifies the format of a default metadata clue. Use this to create automatic “self-referential” clues, as well as static assignments based on the term name in the document metadata. “[TermName]” enables dynamic lookup of the classes name.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Count Mode            | Sets the display mode for counts in the treeview.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Show Empty Nodes      | Sets the display mode for empty nodes in the treeview.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Synchronise Termset   | Enables/Disables automatic synchronisation through the TermStoreManager tool for the whole Term Set.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
