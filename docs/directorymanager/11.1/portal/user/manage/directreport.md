# Manage Your Direct Reports in Directory Manager

To view the users and contacts that report directly to you, click **Users** on the left navigation bar and select **My Direct Reports**.

The page lists the direct reports for which you are the primary manager. To include the direct reports for which you are an additional manager, select the **Display Additional Manager Direct Reports** checkbox on the User Settings panel.

**You can:**

- View and modify the properties of a direct report.

  The properties of a direct report are the same as the properties of a user or contact. Refer to the information for user or contact properties to manage them.

- Select a direct report and click **Delete** on the toolbar to delete it from the directory.
- Select a direct report and click **Managed By** on the toolbar to list all groups the direct report manages. These are the groups for which the direct report is a primary or additional owner.
- Select a direct report and click **Add to Contacts** on the toolbar. The portal creates the vCard of the direct report and prompts you to save it on your machine. You can then use it to add the email address of the direct report to your email contact list.
- Select a direct report and click **Add to Group** on the toolbar to add it to the membership of a group. The [Find Users, Groups, and Contacts in Directory Manager](/docs/directorymanager/11.1/portal/generalfeatures/find.md) page appears. Search for and select the groups to add the direct report to as a member.
- Select a direct report and click **Send email** on the toolbar to send an email to it. This launches the default Windows email application.
- Click **Export Results** on the toolbar to export the direct report list to a Microsoft Excel file.

Use the page numbers under the direct report listing to page through the records.

To control the number of records displayed per page, modify the **Search results per page** setting on the User Settings panel. You can modify the search results in Modify Search Directory. You can select the entire directory or a domain to search active groups from.

:::note
You can't add or remove direct reports on this page. Use the Organization tab of your profile to add or remove your direct reports. You can also transfer and terminate your direct reports while you validate your Profile.
:::

To view any changes made to your direct reports, see the [View My Direct Reports' History in Directory Manager](/docs/directorymanager/11.1/portal/history/mydirectreport.md) topic.
