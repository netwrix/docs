# DNS: Results

The Results page is where you select the DNS properties to gather. It's a wizard page for all
categories.

![Domain Name System Data Collector Wizard Results page](/images/accessanalyzer/12.0/admin/datacollector/dns/results.webp)

You can select available properties individually, or use the **Select All**, **Clear All**, and
**Reset to defaults** buttons. Access Analyzer gathers all selected properties. Available properties
vary based on the category selected.
