# CLAUDE.md — Privilege Secure API

Guidance for working in `docs/privilegesecure/26.07/api/`.

## Layout

```
api/
├── CLAUDE.md             # This file
├── _category_.json       # Top-level "API" section (position 750, after Integrations, before Troubleshooting)
├── overview.md           # Hand-authored: base URL, conventions, paging, errors
├── authentication.md     # Hand-authored: sign-in, tokens, application users
└── reference/            # Generated from the OpenAPI spec
    ├── _category_.json   # Tracked; customProps.isGeneratedApiSidebar triggers the structured sidebar
    ├── index.md          # Tracked; hand-authored intro to the reference
    ├── sidebar.ts        # Generated; loaded by src/config/products.js (apiSidebarPath)
    └── *.mdx             # Generated; gitignored
```

## OpenAPI spec

**Source:** `static/openapi/privilegesecure-26.07.json`, the public spec for 26.07.3. It is generated from the product code and is published as-is; do not edit it by hand. The pipeline, the public/hidden rule and the rebuild steps are in `tools/api-inventory/README.md`. The inputs and the full internal spec are internal and never go in this repo's commits.

At build time `scripts/prepare-privilegesecure-spec.mjs` writes a derived copy to `.generated/` (schemas inlined to depth 1, unique operation IDs) that the plugin reads. The derived copy is never published.

## Regenerating the reference

The `.mdx` files are gitignored and regenerated by `npm run build` and `npm run start`. In the container:

```bash
docker compose run --rm -T privilegesecure sh -c "node scripts/prepare-privilegesecure-spec.mjs static/openapi/privilegesecure-26.07.json .generated/privilegesecure-26.07.json 1 && npx docusaurus clean-api-docs privilegesecure-api --plugin-id openapi-privilegesecure && npx docusaurus gen-api-docs privilegesecure-api --plugin-id openapi-privilegesecure"
git checkout -- docs/privilegesecure/26.07/api/reference/_category_.json   # clean-api-docs deletes it
```

## Sidebar

`reference/_category_.json` carries `isGeneratedApiSidebar`; `sidebarItemsGenerator` in `src/config/products.js` swaps in the tag-grouped sidebar from `sidebar.ts`.
