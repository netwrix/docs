# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Product

**Netwrix Threat Prevention** monitors, alerts on, and can block activity in Active Directory, Exchange, Group Policy, file systems, and credential operations, in real time on domain controllers and Exchange servers. Administrators work in the Administration Console or with PowerShell cmdlets. It integrates with Netwrix Threat Manager, which is a separate product.

The product was formerly named **StealthINTERCEPT**. Don't introduce this name into documentation. Use "Netwrix Threat Prevention" on first reference and "Threat Prevention" after that. The 8.1 pages use "Enterprise Manager" and "Administration Console".

## Versions

Documented versions: **7.4**, **7.5**, **8.0**, and **8.1** (latest). Edits to one version do **not** propagate to the others. Update each version the change applies to.

The sidebar is autogenerated from the folders (`sidebars/threatprevention/*.js`), so place new pages by folder and `sidebar_position`.

## Content Structure

| Folder | Purpose |
|---|---|
| `requirements/` | Application, Administration Console, agent, SQL Server, EPE REST site, reporting server, ports |
| `install/` | Application, agent, first launch, certificate wizard, upgrade, migrating the Enterprise Manager server |
| `admin/` | Administration Console: navigation, policies, templates, agents, alerts, analytics, configuration, investigate, tools |
| `admin/policies/configuration/eventtype/` | One page per event type |
| `admin/policies/configuration/actions/` | Actions |
| `admin/analytics/` | One page per analytic |
| `admin/configuration/` | Collection manager, event filtering, EPE settings, Threat Manager configuration |
| `api/` | PowerShell cmdlets and the EPE API |
| `solutions/` | Active Directory, Exchange, file system, LDAP, EPE |
| `siemdashboard/`, `reportingmodule/`, `eperestsite/` | SIEM dashboard, reporting, EPE REST site |
| `troubleshooting/` | Troubleshooting |
| `kb/` | Knowledge base articles |

Each section has an `overview.md`. Pages are task and reference pages for each screen or option.

## Terminology

| Old or internal name | Use |
|---|---|
| StealthINTERCEPT, SI | Netwrix Threat Prevention |
| WinConsole | Administration Console |
| Lockdown | Blocking (as in "Active Directory Lockdown") |
| Recognizer | Analytics policy |
| EPE | Enterprise Password Evaluation (spell out on first reference) |

Check that an analytic exists in the docs before you document it from the code. Some analytics have no docs page, and some are named differently.
