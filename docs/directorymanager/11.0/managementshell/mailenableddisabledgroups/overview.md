# Directory Manager Mail-Enable and Mail-Disable Group Cmdlets

This section covers cmdlets for enabling and disabling groups for email.

- [Disable-DistributionGroup Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/mailenableddisabledgroups/disabledistributiongroup.md):
  disables a group's email capability.
- [Enable-DistributionGroup Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/mailenableddisabledgroups/enabledistributiongroup.md):
  enables a group's email capability.
