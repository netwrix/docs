# Choose a Job Template in Directory Manager Synchronize

To create a job, use Directory Manager Synchronize to create a new job based on your settings and
criteria. You can also choose from multiple templates to directly create a job.

**Follow these steps:**

1. In the Directory Manager portal, select **Synchronize** in the left pane.
2. In the Synchronize portal, click **Create New** and then click **Job**.
3. On the **Choose Your Job Template** page, enter the following job details:

    1. In **Job Name**, enter a name for the job you are creating.
    2. In **Job Description**, enter a description for the job.
    3. In **Job Owner (s)**, select one or more owners for the job.
    4. To create a new job without a template, select **Blank Job**.
    5. To use a predefined template, click the card of one of the following templates:

        - Linked Mailbox Creation in Active Directory
        - Move and Disable Objects in Active Directory
        - Move Objects in Active Directory
        - Sync GAL in Active Directory
