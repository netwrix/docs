# Create a Data Source API in GroupID

Use this API to create data sources for the supported providers. Data sources are
primarily used in Synchronize jobs, but you can also use them in queries to search for directory
objects and in queries for group membership update.

- [Create a Text/CSV Data Source with the GroupID API](/docs/directorymanager/11.0/apis/datasource/createds/dstext.md)
- [Create an MS Access Data Source with the API](/docs/directorymanager/11.0/apis/datasource/createds/dsaccess.md)
- [Create an MS Excel Data Source with the API](/docs/directorymanager/11.0/apis/datasource/createds/dsexcel.md)
- [Create an ODBC Data Source with the API](/docs/directorymanager/11.0/apis/datasource/createds/dsodbc.md)
- [Create an Oracle Data Source with the GroupID API](/docs/directorymanager/11.0/apis/datasource/createds/dsoracle.md)
- [Create a SQL Server Data Source with the GroupID API](/docs/directorymanager/11.0/apis/datasource/createds/dssql.md)
