# Delete a Workflow Request Using the API

Delete a workflow request from the identity store ID specified in the endpoint URL.

## Endpoint

**https://machinename:4443/GroupIDDataService/api/IdentityStores/{identitystoreId}/Workflows/{WorkflowRequestID}**

## HTTP Methods

**DELETE**

### Sample Response Syntax

```
true
```
