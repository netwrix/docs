# Directory Manager Identity Store Cmdlets

This section covers cmdlets for performing identity store-related tasks such as:

- [Clear-MessagingServer](/docs/directorymanager/11.1/managementshell/identitystore/clearmessagingserver.md) – Removes a configured messaging server.
- [Clear-Notifications Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/clearnotifications.md) – Removes notification settings of an identity store.
- [Clear-SmtpServer Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/clearsmtpserver.md) – Removes a configured SMTP server of an identity store.
- [Get-AvailableMessagingServers Cmdlet](/docs/directorymanager/11.1/managementshell/identitystore/getavailablemessagingservers.md) – Retrieves messaging servers for
  the configured messaging provider.
- [Get-Client Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/getclient.md) – Lists information about the Directory Manager clients.
- [Get-IdentityStore Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/getidentitystore.md) – Retrieves information about an identity store.
- [Get-IdentityStoreRoles Cmdlet](/docs/directorymanager/11.1/managementshell/identitystore/getidentitystoreroles.md) – Retrieves information about the security
  roles in an identity store.
- [Get-LogSettings Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/getlogsettings.md) – Provides information about the global log settings of an
  identity store.
- [Get-RolePermissionNames Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/getrolepermissionnames.md) – Lists the permissions assigned to the
  signed-in user.
- [Get-SchemaAttributes Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/getschemaattributes.md) – Lists schema attributes available for an identity
  store.
- [Get-SmsGateways Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/getsmsgateways.md) – Provides information of the configured SMS gateways.
- [Get-UserRole Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/getuserrole.md) – Displays role information of a user in an identity store.
- [New-IdentityStore Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/newidentitystore.md) – Creates a new identity store.
- [Remove-IdentityStore](/docs/directorymanager/11.1/managementshell/identitystore/removeidentitystore.md) – Removes an identity store from Directory Manager.
- [Send-TestNotification](/docs/directorymanager/11.1/managementshell/identitystore/sendtestnotification.md) – Sends a test notification.
- [Set-IdentityStore](/docs/directorymanager/11.1/managementshell/identitystore/setidentitystore.md) – Modifies an identity store configuration.
- [Set-IdentityStoreRole](/docs/directorymanager/11.1/managementshell/identitystore/setidentitystorerole.md) – Modifies properties of a security role in an
  identity store.
- [Set-MessagingServer](/docs/directorymanager/11.1/managementshell/identitystore/setmessagingserver.md) – Configures a messaging server in an identity store.
- [Set-Notifications Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/setnotifications.md) – Modifies notification settings of an identity store.
- [Set-SmtpServer Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/identitystore/setsmtpserver.md) – Configures an SMTP server of an identity store.
