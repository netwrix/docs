# Create a Microsoft Teams Group in Directory Manager

In the Directory Manager portal, you can create a team in the identity store.

## Create Teams

1. In the Directory Manager portal, click **Create New** and select **Team**. The **Create Group** wizard opens to the **Group Type** page.

   Pages and fields in the wizard can vary, because the administrator can customize the wizard by adding or removing pages and fields.

2. On the [Select a group type in Directory Manager](/docs/directorymanager/11.2/portal/group/create/grouptype.md) page, select the group type and click **Next**.
3. On the General page, specify basic information about the group.
4. If you select Static Group, specify members for the group on the [Members Page in the Create Group Wizard](/docs/directorymanager/11.2/portal/group/create/AD/members.md).
5. If you select Smart Group or a Dynasty, review and modify the query that updates group membership on the [Smart Group Page in the Create Group Wizard](/docs/directorymanager/11.2/portal/group/create/AD/smartgroup.md).
6. On the [Owners Page in the Create Group Wizard](/docs/directorymanager/11.2/portal/group/create/AD/owners.md), specify the primary and additional owners for the group.
7. On the [Review the Summary Page Before Creating an Object](/docs/directorymanager/11.2/portal/user/create/AD/summary.md), review the settings and click **Finish** to complete the wizard.
