# What's New

Release notes for Netwrix Endpoint Protector are published on the Netwrix Community. See the [Endpoint Protector release notes](https://community.netwrix.com/c/endpoint-protector/news/106) for new features, improvements, and fixes in the current release.

The Endpoint Protector News page on the Community is the place to find release notes. The Server and the Client publish their release notes as separate posts.
