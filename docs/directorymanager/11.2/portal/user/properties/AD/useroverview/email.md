# View Email Addresses and Subscriptions in Directory Manager

Use the **Email** tab to view the addresses assigned to an object and to manage its subscriptions.

## Addresses

**Addresses**

For a mail-enabled object, the messaging provider (such as Microsoft Exchange) assigns different addresses for communication with different repositories (such as Address Book, SIP, and Outlook). This box displays these addresses.

## Subscriptions

**Subscriptions**

This section displays the subscriptions assigned to the mailbox. It also lists other subscriptions that Office 365 offers to a mailbox user. Select the checkbox for a subscription to assign it to the mailbox.

The subscription list appears for mailbox objects when Office 365 is the messaging provider for the identity store.
