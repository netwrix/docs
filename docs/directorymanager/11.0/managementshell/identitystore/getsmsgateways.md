# Get-SmsGateways Cmdlet in GroupID

The Get-SmsGateways cmdlet provides information about the SMS gateways configured in GroupID.

## Syntax

```
Get-SmsGateways
[<CommonParameters>]
```

## Required Parameter

- None

Example:

This example lists all the configured SMS gateways in GroupID.

```
Get-SmsGateways
```
