# Directory Manager Contact Properties in Active Directory

You can view and edit the properties of contacts in Active Directory.

## Contact properties

Contacts have the following property tabs in an Active Directory-based identity store.

- [Object properties - General tab](/docs/directorymanager/11.2/portal/user/properties/AD/useroverview/general.md)
- [Object properties - Organization tab](/docs/directorymanager/11.2/portal/user/properties/AD/useroverview/organization.md)
- [Contact properties - Member Of tab](/docs/directorymanager/11.2/portal/user/properties/AD/contact/memberof.md)
- [Object properties - Phone / Notes tab](/docs/directorymanager/11.2/portal/user/properties/AD/useroverview/phonenote.md)
- [Object properties - Attributes tab](/docs/directorymanager/11.2/portal/group/properties/attributes.md)
- [Object properties - Email tab](/docs/directorymanager/11.2/portal/user/properties/AD/useroverview/email.md)
- [Contact properties - Advanced tab](/docs/directorymanager/11.2/portal/user/properties/AD/contact/advanced.md)
- [Object properties - History tab](/docs/directorymanager/11.2/portal/group/properties/history.md)
