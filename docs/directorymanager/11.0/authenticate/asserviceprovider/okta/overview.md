# Configure Okta Single Sign-On for GroupID

Okta provides secure identity management and single sign-on to any application, whether in the
cloud, on-premises, or on a mobile device, for the employees of an organization.

To configure single sign-on in GroupID using Okta as the provider:

- Generate the consumer URL and audience URL for the GroupID client with which you want to
  configure Okta.
- Configure GroupID in Okta.
- Configure the Okta provider in GroupID.

After that, you can sign in to GroupID using Okta.
