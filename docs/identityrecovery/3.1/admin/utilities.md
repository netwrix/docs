# Utilities Page

The Utilities page lets you download installers for the Identity Recovery components that run outside
the Recovery Console. All users who can sign in to the Recovery Console can open this page.

Click **Utilities** in the left pane to open the Utilities page.

![Utilities Page](/images/identityrecovery/3.1/product/utilities.png)

The page displays a card for each utility. Click **Download** on a card to download its installer.

- Netwrix RSAT Extension – Extends the Microsoft management utilities so you can roll back and recover
  objects from the administration tools you already use. The installer is
  `NetwrixRecovery_RSAT_Extension.msi`. See the
  [Install the RSAT Extension](/docs/identityrecovery/3.1/install/installation.md) topic for additional
  information.
- Recovery Server Backup Installer – Installs the component that backs up domain controllers to protect
  against forest disaster scenarios. The installer is `NetwrixRecovery_Server_Backup_Installer.msi`. See
  the [Forest Page](/docs/identityrecovery/3.1/admin/forest/forest.md) topic for information on domain
  controller backups.
- Netwrix Forest Recovery – A standalone application that recovers from a complete forest disaster,
  including when no authentication mechanisms are available. The installer is
  `Netwrix_Forest_Recovery_Installer.msi`. See the
  [Recover a Forest](/docs/identityrecovery/3.1/admin/forest/recover.md) topic for information on forest
  recovery.
