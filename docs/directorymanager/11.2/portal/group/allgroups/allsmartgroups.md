# View Smart Groups in Directory Manager

This view lists only the Smart Groups created in Directory Manager for the connected identity store. It doesn't list expired or deleted Smart Groups. To view expired or deleted groups, see [View Expired Groups in Directory Manager](/docs/directorymanager/11.2/portal/group/allgroups/allexpiredgroups.md) or [Restore or Delete Groups in the Directory Manager Recycle Bin](/docs/directorymanager/11.2/portal/group/recyclebin/overview.md).

To search Smart Groups, [Modify Search Directory](allgroups.md#modify-search-directory). To narrow the list, click **Smart Group Grid Filter** and [Filter All Groups](allgroups.md#filter-all-groups). All the Smart Groups that match the filters appear.
