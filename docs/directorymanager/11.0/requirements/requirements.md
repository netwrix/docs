# Directory Manager 11.0 System Requirements

This page lists the hardware, operating system, Microsoft Exchange, and database requirements for
running Directory Manager 11.0. The prerequisites might vary depending on your environment.

- [Directory Manager Hardware Requirements](/docs/directorymanager/11.0/requirements/hardware.md)
- [Windows Server Requirements for Directory Manager](/docs/directorymanager/11.0/requirements/windowsserver.md)
- [Directory Manager Supported Exchange Servers](/docs/directorymanager/11.0/requirements/exchange_servers.md)
- [Directory Manager Database Requirements](/docs/directorymanager/11.0/requirements/database.md)

Before installation, the
[Run the Directory Manager Preparation Tool](/docs/directorymanager/11.0/about/installer/preparationtool.md)
installs the required software and Windows features. See the
[Software the Directory Manager Preparation Tool Installs](/docs/directorymanager/11.0/about/installer/whatprepinstall.md)
topic for the list of components the tool installs.
