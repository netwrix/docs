# What's new

This page lists what each AI Security release adds, newest first. Each entry says what you can do that you couldn't do before.

## 1Secure AI Security Beta

{/* TODO: add the release date before publishing. */}

The first release of AI Security in 1Secure.

- **Get started.** A first run that asks where agents could be running, connects the sources you pick, and starts the first scan.
- **Connect with Microsoft.** One sign-in by a Global Administrator or Privileged Role Administrator connects Microsoft Entra ID and the Microsoft sources that read with it. You paste nothing.
- **Sources.** The platforms you can connect, each with a connector page of its own. Eight more show **Coming soon** and can't be connected yet. [Known limitations](/docs/1secureaisecurity/troubleshooting/known-limitations.md) names them.
- **Scans.** A scan of every connected source, with each source's result, what wasn't read, and what to do about it.
- **Pages.** Overview, Agents, Identities, Issues, Shadow AI, Sources, Alerts, and Settings.
