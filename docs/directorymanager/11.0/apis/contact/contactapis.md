# Directory Manager Contact APIs

Directory Manager provides the following APIs to perform contact-specific functions:

- [Create a Contact with the Directory Manager API](/docs/directorymanager/11.0/apis/contact/createcontact.md)
- [Delete a Contact with the Directory Manager API](/docs/directorymanager/11.0/apis/contact/deletecontact.md)
- [Delete Multiple Contacts with the Directory Manager API](/docs/directorymanager/11.0/apis/contact/deletecontacts.md)
- [Get a Contact with the Directory Manager API](/docs/directorymanager/11.0/apis/contact/getcontact.md)
- [Get Contacts API in Directory Manager](/docs/directorymanager/11.0/apis/contact/getcontacts.md)
- [Update a Contact API in Directory Manager](/docs/directorymanager/11.0/apis/contact/updatecontact.md)

:::note
The contact object type isn't supported in a Microsoft Entra ID-based identity store.
:::
