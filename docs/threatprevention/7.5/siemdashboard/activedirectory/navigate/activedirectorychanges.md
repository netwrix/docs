# Active Directory Changes Dashboard

The Active Directory Changes dashboard contains the following cards:

![Active Directory Changes Dashboard](/images/threatprevention/7.5/siemdashboard/splunk/activedirectory/dashboard/adchanges.webp)

- Changes by Type – Breakdown of changes by event type in the specified timeframe
- Successful/Blocked Events – Breakdown of changes by successful, failed, or blocked status in the specified timeframe
- Changes by Domain – Breakdown of changes by domain in the specified timeframe
- Top Client IPs – Shows the top five client IP addresses associated with events in the specified timeframe
- Top Perpetrators – Shows the top five perpetrator usernames associated with events in the specified timeframe
- Change Events – Tabular format of all Active Directory change events in the specified timeframe

The timeframe defaults to the last 24 hours (past day).
