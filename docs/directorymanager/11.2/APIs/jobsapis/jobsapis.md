# Synchronize Jobs APIs

Directory Manager Synchronize transfers data from one data source to another. The
data sources may include directory servers, databases, or files. Use the following APIs to
perform Synchronize jobs-specific functions:

- [Create a New Job](/docs/directorymanager/11.2/APIs/jobsapis/createjob.md)
- [Create a New Job Collection](/docs/directorymanager/11.2/APIs/jobsapis/createnewjobcollection.md)
- [Delete Jobs](/docs/directorymanager/11.2/APIs/jobsapis/deletejob.md)
- [Delete Job Collections](/docs/directorymanager/11.2/APIs/jobsapis/deletejobcollections.md)
- [Get Job Collections Details](/docs/directorymanager/11.2/APIs/jobsapis/getcollectionsdetails.md)
- [Get Job Collection Details By Job Collection ID](/docs/directorymanager/11.2/APIs/jobsapis/getjcdetailsbyjcid.md)
- [Get Jobs](/docs/directorymanager/11.2/APIs/jobsapis/getjobs.md)
- [Get Job Collections](/docs/directorymanager/11.2/APIs/jobsapis/getjobcollections.md)
- [Get a Job Details](/docs/directorymanager/11.2/APIs/jobsapis/getjobsdetails.md)
- [Get Jobs Names ](/docs/directorymanager/11.2/APIs/jobsapis/getjobsname.md)
- [Update a Job Collection](/docs/directorymanager/11.2/APIs/jobsapis/updatjobcollection.md)
