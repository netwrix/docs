# WMICollector: Classes

On the Classes page, configure the WMICollector namespaces and classes to use as a data source.

![WMI Browser wizard Classes page](/images/accessanalyzer/12.0/admin/datacollector/wmicollector/classes.webp)

Select the **Namespace** and **Class** from the dropdown lists to use as a data source. You
typically use the default namespace, **root\CIMV2**. Select the **Win32 classes only**
checkbox to use only Win32 classes.
