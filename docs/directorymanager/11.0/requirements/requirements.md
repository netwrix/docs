# GroupID 11.0 System Requirements

This page lists the hardware, operating system, Microsoft Exchange, and database requirements for
running GroupID 11.0. The prerequisites might vary depending on your environment.

- [GroupID Hardware Requirements](/docs/directorymanager/11.0/requirements/hardware.md)
- [Windows Server Requirements for GroupID](/docs/directorymanager/11.0/requirements/windowsserver.md)
- [GroupID Supported Exchange Servers](/docs/directorymanager/11.0/requirements/exchange_servers.md)
- [GroupID Database Requirements](/docs/directorymanager/11.0/requirements/database.md)

Before installation, the
[Run the GroupID Preparation Tool](/docs/directorymanager/11.0/about/installer/preparationtool.md)
installs the required software and Windows features. See the
[Software the GroupID Preparation Tool Installs](/docs/directorymanager/11.0/about/installer/whatprepinstall.md)
topic for the list of components the tool installs.
