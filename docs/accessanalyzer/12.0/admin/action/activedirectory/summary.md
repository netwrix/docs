# Active Directory Action Summary

The Summary page displays a summary of the configured settings for the action.

![Active Directory Action Module Wizard Summary page](/images/accessanalyzer/12.0/admin/action/activedirectory/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel** to
close the Active Directory Action Module Wizard instead. This prevents the wizard from saving
accidental clicks.
