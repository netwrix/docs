# Product Tour

New users see a product tour on first login. The tour walks standard users and users with the
Privilege Secure administrator role through features that are relevant to their role.

![Product tour walkthrough shown on first login](/images/privilegesecure/25.12/accessmanagement/enduser/producttour.webp)

At any time, you can stop the tour by clicking the **X** icon at the top-right of the Console. By
default, the tour won't display on next login unless you clear the **don't display again**
checkbox.

You can restart the product tour at any time from the user menu.

![User menu in the Console](/images/privilegesecure/25.12/accessmanagement/enduser/usermenu.webp)

See the [Navigation](/docs/privilegesecure/25.12/admin/navigation/navigation.md) topic for additional information.
