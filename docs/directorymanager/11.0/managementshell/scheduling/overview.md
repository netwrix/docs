# Directory Manager Scheduling Cmdlets

This section covers the cmdlets that perform scheduling-related operations.

- [Get-Schedule Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/scheduling/getschedule.md):
  retrieves scheduled jobs.
- [Get-TargetSchedules Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/scheduling/gettargetschedule.md):
  retrieves the scheduled jobs operating on a group or OU.
- [Invoke-Schedule Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/scheduling/invokeschedule.md):
  executes a scheduled job.
- [New-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.0/managementshell/scheduling/newschedule.md):
  creates a new schedule.
- [Remove-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.0/managementshell/scheduling/removeschedule.md):
  removes a schedule from an identity store.
- [Set-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.0/managementshell/scheduling/setschedule.md):
  modifies a schedule.
- [Stop-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.0/managementshell/scheduling/stopschedule.md):
  stops a running schedule.
