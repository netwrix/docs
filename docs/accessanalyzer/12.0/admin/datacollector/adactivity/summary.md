# ADActivity: Summary

The Summary page summarizes the configuration settings. This wizard page appears for all
categories.

![Active Directory Activity DC wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/adactivity/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** to close
the Active Directory Activity DC wizard instead. This ensures the wizard doesn't save any
accidental clicks.
