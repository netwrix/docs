# Send Reminders Window

The Send Reminders window opens from the [Manage Reviews Page](/docs/accessinformationcenter/12.0/resourcereviews/interface/interface.md#manage-reviews-page)
of the Resource Reviews interface. Select the active reviews you want and click **Send Reminders**
to send immediate reminder notifications. The Send Reminders window opens to display an action
status.

![Send Reminders window](/images/accessinformationcenter/12.0/resourcereviews/window/sendreminders.webp)

The window displays the action status. When the status indicates success, the application sends a reminder email to assigned owners. Click **OK** to close the Send Reminders window.

:::tip
Automatic weekly reminders can be configured on the [Notifications Page](/docs/accessinformationcenter/12.0/admin/configuration/notifications.md) of the Configuration interface.
:::
