# Manage the Directory Manager Notification Queue

Directory Manager keeps a queue of the email notifications generated by events in the identity
stores. It sends them one by one through the SMTP server configured for the respective identity
store. Each new email notification goes to the top of the queue.

When the SMTP server for an identity store is down, Directory Manager can't deliver the queued
notifications. It attempts to resend them until they're delivered. Delivered notifications leave the
queue.

The Email service queues and sends notifications. You can also send or delete notifications
manually. Admin Center history tracks both actions.

Directory Manager also has a Notification Editor that lists the notification templates for all
notifications that Directory Manager generates on various events. See the
[Customize Directory Manager Notification Templates](/docs/directorymanager/11.1/admincenter/notification/customize.md)
topic for details.

## View the Notification Queue

In Admin Center, click **Notifications** in the left pane. The **Notification Queue** page shows the
following for each notification:

- **Subject:** the subject line of the email notification
- **Date:** the date and time the notification was generated
- **To:** the notification recipients specified in the To line
- **From:** the email ID of the sender
- **CC:** the notification recipients specified in the CC line
- **Last Retry:** the date and time of the most recent attempt to send the notification
- **Retry Count:** the total number of attempts to send the notification
- **In Progress:** one of the following statuses for a notification:

  - **True:** the notification is being processed for sending
  - **False:** the notification isn't being processed

  Directory Manager processes notifications in batches, so all notifications in a batch have the
  same status.

### Filter Notifications

Click **Filter** to filter the notifications by status, either pending or failed.

In the **Categories** list on the **Filter** dialog box, select one of the following and click
**Apply**:

- **Pending:** shows notifications that are queued for sending. The Email service hasn't yet
  attempted to send them.
- **Failed:** shows notifications that the Email service attempted to send but failed. The retry
  count for these notifications increases by ‘1’ on every failed attempt.
- **All:** shows all pending and failed notifications in the queue.

### Available Actions

- Click **Send** for a notification in the **Actions** column to send it urgently, without waiting
  for the Email service to send it in turn.
- Click **Delete** for a notification in the **Actions** column to delete it.
- Click **Refresh** to refresh the notification queue.
- Click **Notification Editor** to launch the Notification Editor, where you can view and modify
  notification templates. See the
  [Customize Directory Manager Notification Templates](/docs/directorymanager/11.1/admincenter/notification/customize.md)
  topic for details.

## Send a Notification Urgently

You can send a single notification or several notifications urgently, rather than waiting for the
Email service to send them in order. Admin Center history tracks all manual attempts to send
notifications.

1. In Admin Center, click **Notifications** in the left pane.
2. On the **Notification Queue** page, send one or more notifications:

   - Click **Send** for a notification in the **Actions** column to send it urgently.
   - To send several notifications, select their checkboxes. To select all notifications, select
     the checkbox in the header row. These icons appear:

     ![Send and Delete icons displayed above the selected notifications](/images/directorymanager/11.1/admincenter/notification/send_refresh.webp)

     Click the **Send** icon to send the selected notifications urgently.

## Delete a Notification

Delete a notification in the queue to prevent Directory Manager from sending it. Admin Center
history logs deletion events.

To delete a notification:

1. In Admin Center, click **Notifications** in the left pane.
2. On the **Notification Queue** page, delete one or more notifications:

   - Click **Delete** for a notification in the **Actions** column to delete it.
   - To delete several notifications, select their checkboxes. To select all notifications, select
     the checkbox in the header row. These icons appear:

     ![Send and Delete icons displayed above the selected notifications](/images/directorymanager/11.1/admincenter/notification/send_refresh.webp)

     Click the **Delete** icon to delete the selected notifications.
