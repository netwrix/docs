# Manage Directory Manager Applications

In Admin Center, you can create and manage the following Directory Manager applications:

- [Directory Manager Portal](/docs/directorymanager/11.2/admincenter/applications/portal/overview.md)
- [Directory Manager Data Service](/docs/directorymanager/11.2/admincenter/service/dataservice/overview.md)
- [Security Service in Directory Manager](/docs/directorymanager/11.2/admincenter/service/securityservice/overview.md)

You can also manage some basic deployment and log settings for the following applications:

- [Directory Manager Admin Center Application](/docs/directorymanager/11.2/admincenter/applications/admincenter.md)
- [Directory Manager Replication Service](/docs/directorymanager/11.2/admincenter/service/replicationservice.md)
- [Directory Manager Email Service](/docs/directorymanager/11.2/admincenter/service/emailservice.md)
- [Directory Manager Scheduler Service](/docs/directorymanager/11.2/admincenter/service/schedulerservice.md)

For more information, see the [Directory Manager Services](/docs/directorymanager/11.2/admincenter/service/overview.md) topic.
