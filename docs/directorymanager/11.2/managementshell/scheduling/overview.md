# Directory Manager Scheduling Cmdlets

These cmdlets perform scheduling operations.

- [Get-Schedule Cmdlet in Directory Manager](/docs/directorymanager/11.2/managementshell/scheduling/getschedule.md) – Retrieves scheduled jobs.
- [Get-TargetSchedules Cmdlet in Directory Manager](/docs/directorymanager/11.2/managementshell/scheduling/gettargetschedule.md) – Retrieves the scheduled jobs that operate on a group or OU.
- [Invoke-Schedule Cmdlet in Directory Manager](/docs/directorymanager/11.2/managementshell/scheduling/invokeschedule.md) – Runs a scheduled job.
- [New-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.2/managementshell/scheduling/newschedule.md) – Creates a schedule.
- [Remove-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.2/managementshell/scheduling/removeschedule.md) – Removes a schedule from an identity store.
- [Set-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.2/managementshell/scheduling/setschedule.md) – Modifies a schedule.
- [Stop-Schedule Cmdlet for Directory Manager](/docs/directorymanager/11.2/managementshell/scheduling/stopschedule.md) – Stops a running schedule.
