# Web Site Platform Policy Configuration

The Web Site menu displays the configuration options for Web Site platforms.

![Website Platform Configuration](/images/privilegesecure/26.03/accessmanagement/admin/policy/page/platforms/website.webp)

Details for the selected platform display on the right side of the page. The following are the
configuration options for a Website Platform.

- **Name** — Displays the name of the policy
- **Description** — Description of the policy

If you modify any of these settings, **Save**, and **Cancel** buttons appear. Click **Save** to
commit the modifications. Click **Cancel** to discard the modifications.
