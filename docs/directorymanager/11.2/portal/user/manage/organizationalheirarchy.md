# View the Organizational Hierarchy in Directory Manager

You can view the organizational hierarchy for a user. It shows the direct reports of the reference user recursively, starting from the immediate direct reports and moving downward to the nth level. The hierarchy appears in graphical form as an organogram that displays the email address, photo, and other attributes of each user.

By default, the chart appears for the logged-in user. However, the user can view it for any user in the organization.

## View the direct reports of a user

1. In the Directory Manager portal, go to **My Profile**. Or search for the user whose organizational hierarchy you want to view in the [Search Directory Objects in the Directory Manager Portal](/docs/directorymanager/11.2/portal/generalfeatures/search.md) dialog box.

2. On the toolbar tab of the user profile page, select **Organizational Hierarchy**. The **Organizational Hierarchy** page displays the direct reports of the logged-in user recursively to the nth level.

3. To view the chart for another user, click the ellipsis button next to **Select User**.

   In the [Find Users, Groups, and Contacts in Directory Manager](/docs/directorymanager/11.2/portal/generalfeatures/find.md) page, search for and select the required user, and click **OK**. The page displays the organizational hierarchy chart for the selected user.

4. You can do any of the following:

   - Click a user's name to view their profile.
   - Click a user's email address to send an email to them.
   - Use the Export button to export the chart to a PNG file.
