# Installing Window

The Deploy Agents wizard's Installing window is the last in a sequence of four windows to deploy the
Agent on a computer. This window executes the deployment, tracks the process, and
displays a successful or failed status.

![Deploy Agents wizard – Installing page](/images/threatprevention/8.0/admin/agents/deploy/installing.webp)

It displays the working and completed status of the action. Depending on whether the system deploys the
Agent successfully, the Message column displays a failed message with additional text or a
successful message if the system deploys the Agent correctly.

To stop the deployment process on any machines that haven't yet started deployment, click Cancel.
The Close button changes to a Finish button after the system deploys all Agents.
