# TextSearch: Summary

The Summary page displays a summary of the configured query.

![Text Search Data Collector Wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/textsearch/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the Text Search Data Collector Wizard without saving accidental clicks.
