# View Expiring Groups in Directory Manager

This page shows only the expiring groups in the connected identity store.

Groups that expire in 30 days or less are considered expiring groups. The expiry date is
calculated from a group’s expiry policy. The Group Lifecycle job is responsible for expiring these
groups on their respective expiry dates. You can also manually expire a group before it reaches the
expiry date.

You can
[Modify Search Directory](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#modify-search-directory)
to search expiring groups and add
[Filter All Groups](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#filter-all-groups)
by clicking **Expiring Group Grid Filters**. All the expiring groups matching the filters appear.
