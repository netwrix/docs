# What's New

Release notes for Netwrix Privilege Secure for Access Management are published on the Netwrix Community. See the [Privilege Secure for Access Management release notes](https://community.netwrix.com/c/privilege-secure/29) for new features, improvements, and fixes in the current release.

## Releases covered

This documentation set is cumulative. It covers these releases:

- 25.12.x
- 26.03.x
- 26.07.0 (limited release to selected customers; 26.07.1 is the general release and includes all of 26.07.0)
- 26.07.1
- 26.07.3

For details, see the [26.07.1 release announcement](https://community.netwrix.com/t/netwrix-privilege-secure-q2-2026-release-26-07-1/136803) and the [26.07.3 release announcement](https://community.netwrix.com/t/patch-version-26-07-3-released-privilege-secure-for-access-management/161358).
