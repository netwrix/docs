# User Notifications

After you assign devices to Device Groups and assign a Configuration Template, Netwrix Change
Tracker records a baseline of the configuration. After that, it can report any detected changes
as email or syslog alerts.

You can assign each Netwrix Change Tracker user a personalized alerting profile from a range of
event options for each Device Group.

Access the **User Notification Email** page via **Settings** -> **User Notification Emails** and
select a user, then configure **Notification Types** for the selected Device Group.

:::note
You must also define core system settings, such as the Syslog Server and SMTP details,
via **Settings** -> **System Settings** in Change Tracker. See the
[System Settings](/docs/changetracker/admin/settingstab/systemsettings/systemsettings.md) topic for additional information.

:::
