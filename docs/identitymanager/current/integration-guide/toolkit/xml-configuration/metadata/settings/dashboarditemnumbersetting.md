Used to customize the number of links to display on each section on the Dashboard. If no value is defined, the default value is 3. The value must be greater than 0 and less than or equal to 5.

## Properties

|Property|Details|
|---|---|
| AccessCertificationSection <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of links to display in the Access Certification section. The value must be greater than 0 and less than or equal to 5. |
| Identifier <span class="optionalAttribute">default value: DashboardItemNumber</span> | **Type:** String **Description:** Unique identifier of the setting. |
| ManualProvisioningSection <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of links to display in the Manual Provisioning section. The value must be greater than 0 and less than or equal to 5. |
| MyTasksSection <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of links to display in the My Tasks section. The value must be greater than 0 and less than or equal to 5. |
| ProvisioningReviewSection <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of links to display in the Provisioning Review section. The value must be greater than 0 and less than or equal to 5. |
| QuickActions <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of quick actions to display in the dashboard. The value must be greater than 0 and less than or equal to 5. |
| QuickEntityTypes <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of entity types to display in the dashboard. The value must be greater than 0 and less than or equal to 5. |
| ResourceReconciliationSection <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of links to display in the Reconciliation Review section. The value must be greater than 0 and less than or equal to 5. |
| RoleReconciliationSection <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of links to display in the Role Reconciliation section. The value must be greater than 0 and less than or equal to 5. |
| RoleReviewSection <span class="optionalAttribute">default value: 3</span> | **Type:** Int32 **Description:** Number of links to display in the Role Review section. The value must be greater than 0 and less than or equal to 5. |
