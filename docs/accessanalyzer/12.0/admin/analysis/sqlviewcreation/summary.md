# SQLViewCreation: Summary

This page provides an overview of all the settings configured in the wizard.

![View and Table Creation Analysis Module wizard Summary page](/images/accessanalyzer/12.0/admin/analysis/sqlviewcreation/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel** to
close the View and Table Creation Analysis Module wizard so you don't save accidental changes.
