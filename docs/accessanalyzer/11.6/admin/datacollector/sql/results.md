# SQL: Results

Use the Results page to select the properties to gather. It's a wizard page for
all of the categories.

![SQL Data Collector Wizard Results Page](/images/accessanalyzer/11.6/admin/datacollector/sql/results.webp)

Select properties individually, or use the **Select All** and **Clear All** buttons.
Enterprise Auditor gathers all selected properties. Available properties vary based on the category
selected.
