# Schedule Synchronize Jobs and Job Collections

The Directory Manager scheduling function lets you configure any Synchronize job or job collection
to run automatically. Create a Synchronize schedule and add Synchronize jobs and job collections as
targets. When the schedule runs, the target jobs and job collections are executed.

To create a Synchronize schedule, see the
[Create a Directory Manager Synchronize Schedule](/docs/directorymanager/11.0/signin/schedule/synchronize.md)
topic.
