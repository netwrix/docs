# Directory Manager group cmdlets

Use these cmdlets to perform tasks related to managed and unmanaged groups.

- [Convert-Group](/docs/directorymanager/11.1/managementshell/group/convertgroup.md) – Converts an unmanaged group to a Smart Group.
- [Expire-Group](/docs/directorymanager/11.1/managementshell/group/expiregroup.md) – Expires a group temporarily.
- [Get-Group](/docs/directorymanager/11.1/managementshell/group/getgroup.md) – Retrieves groups from one or more containers.
- [Move-Group](/docs/directorymanager/11.1/managementshell/group/movegroup.md) – Moves a group to a different container in the same domain or in a
  different domain.
- [New-Group](/docs/directorymanager/11.1/managementshell/group/newgroup.md) – Creates an unmanaged group.
- [Remove-Group](/docs/directorymanager/11.1/managementshell/group/remove-group.md) – Deletes a managed group, unmanaged group, or Dynasty in the
  directory.
- [Renew-Group](/docs/directorymanager/11.1/managementshell/group/renewgroup.md) – Reactivates an expired group.
- [Set-Group](/docs/directorymanager/11.1/managementshell/group/setgroup.md) – Modifies an unmanaged group in the directory.
