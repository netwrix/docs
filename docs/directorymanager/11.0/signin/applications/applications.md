# Manage Directory Manager Applications

Using Admin Center, you can create and manage the following Directory Manager applications:

- [Directory Manager Portal](/docs/directorymanager/11.0/signin/applications/portal/overview.md)
- [Directory Manager Data Service](/docs/directorymanager/11.0/signin/service/dataservice/overview.md)
- [Security Service in Directory Manager](/docs/directorymanager/11.0/signin/service/securityservice/overview.md)
- [Directory Manager Mobile Service Overview](/docs/directorymanager/11.0/signin/service/mobileservice/overview.md)

Moreover, you can manage some basic deployment and log settings for the following applications:

- [Directory Manager Admin Center Application](/docs/directorymanager/11.0/signin/applications/admincenter.md)
- [Directory Manager Replication Service](/docs/directorymanager/11.0/signin/service/replicationservice.md)
- [Directory Manager Email Service](/docs/directorymanager/11.0/signin/service/emailservice.md)
- [Directory Manager Scheduler Service](/docs/directorymanager/11.0/signin/service/schedulerservice.md)
