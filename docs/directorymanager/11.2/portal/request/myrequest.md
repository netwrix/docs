# View Your Workflow Requests in Directory Manager

To view the workflow requests that you initiated, expand the **Requests** node on the left
navigation bar and select **My Requests**. You can view the requests pending approval as well as
requests that have been processed (approved or denied).

By default, the page displays pending requests that you initiated today. You can also filter the
requests by adding filters.

For each request, you can view the description, approvers, requester name, the target to change,
status, the date the request was made, and the reason the request was denied. Expand a request to
view more details, such as the field changed along with its old and new values.
