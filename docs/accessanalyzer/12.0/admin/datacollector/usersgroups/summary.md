# UsersGroups: Summary

The Summary page displays a summary of the configured query.

![Users and Groups Browser wizard Summary page](/images/accessanalyzer/12.0/admin/datacollector/usersgroups/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the Users and Groups Browser wizard without saving accidental clicks.
