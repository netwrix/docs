# Manage Your Request Inbox in Directory Manager

Using the Directory Manager portal, designated approvers can view workflow requests and approve or
deny them. On the left navigation bar, click **Requests**. Then click **Request Inbox** to view the
workflow requests that are waiting for approval. You can also view the request count next to the
**Request Inbox** label.

By default, the page displays pending requests that were initiated today. You can also view
processed (approved or denied) requests. Use filters to narrow the list of requests as needed.

For each request, you can view the description, approvers, requester name, the target to change,
status of the request, creation date, and the reason the request was denied. Expand a request to
view more details, such as the field changed along with its old and new values.

You can perform the following functions on the **Request Inbox** page:

- [Approve a request](/docs/directorymanager/11.0/welcome/request/allrequest.md#approve-a-request).
- [Deny a request](/docs/directorymanager/11.0/welcome/request/allrequest.md#deny-a-request).
- [Filter requests](/docs/directorymanager/11.0/welcome/request/allrequest.md#filter-requests).
