# Directory Manager Portal General Features

The Directory Manager portal provides the following functionalities for users:

- Directory Search
- Find Dialog Box
- Portal Settings
- User Account Settings
- Toolbars

## Directory Search

The Directory Manager portal provides a search feature that lets users manage various directory objects within their identity store. These objects include mailboxes,
users, groups, and contacts. Once a search is performed, the results are displayed on the Search
Results page.

See the [Search Directory Objects in the Directory Manager Portal](/docs/directorymanager/11.1/portal/generalfeatures/search.md) topic for more information.

## Find Dialog Box

With the Find dialog box, you can search User, Group, and Contact objects in the connected identity
store. The object types available for search can vary, depending on the page you launch the
**Find** dialog box from.

See the [Find Users, Groups, and Contacts in Directory Manager](/docs/directorymanager/11.1/portal/generalfeatures/find.md) topic for more information.

## Portal Settings

The Directory Manager portal offers flexible portal settings to customize the user experience and
personalize the portal for each user.

See the [Configure Directory Manager Portal Settings](/docs/directorymanager/11.1/portal/generalfeatures/portal.md) topic for more information.

## User Account Settings

Users can manage their own profile information and perform various account-related actions through
the User Settings.

See the [Manage Your Directory Manager User Account](/docs/directorymanager/11.1/portal/generalfeatures/user.md) topic for more information.

## Toolbars

The portal provides toolbars with diverse options that users can use on the objects. These actions
include editing properties, managing membership, viewing history, and more.

See the [Directory Manager Portal Toolbar Buttons](/docs/directorymanager/11.1/portal/generalfeatures/toolbar.md) topic for more information.
