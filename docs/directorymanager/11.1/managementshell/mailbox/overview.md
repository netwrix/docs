# Mailbox Cmdlets in Directory Manager

Use these cmdlets to perform mailbox tasks:

- [Get-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/mailbox/getmailbox.md) – Retrieves a mailbox.
- [New-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/mailbox/newmailbox.md) – Creates a new mailbox.
- [Remove-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/mailbox/removemailbox.md) – Deletes a mailbox.
- [Set-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.1/managementshell/mailbox/setmailbox.md) – Modifies a mailbox.
