# Find Similar Groups in Directory Manager

Directory Manager compares groups for similarity based on:

- Group type
- Membership

For example, a distribution group (Group A) has three members: Sarah, Frank, and Robin. On
the Similar Groups tab in Group A properties, the portal displays the six groups most similar to
Group A. To rank as similar to Group A, a group must be of the distribution type and have any or
all three of Group A's members.

The six similar groups are sorted by strength, with the strongest match at the top.

To view similarity details, click a group bar or a group in the left pane. The **Similarity Details**
dialog box displays the type and members that both groups share.
