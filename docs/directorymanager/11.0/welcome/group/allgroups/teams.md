# View Microsoft Teams Groups in Directory Manager

This page lists all the Microsoft Teams groups.

You can [Modify Search Directory](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#modify-search-directory) to search teams and add
[Filter All Groups](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#filter-all-groups) by clicking **Teams Grid Filters**. All the teams matching
the filters are displayed.
