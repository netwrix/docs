# SAML Configuration for GroupID Using PingOne

PingOne is an Identity as a Service (IDaaS) solution that enables organizations to deliver single
sign-on with just one username and password.

To configure single sign-on in GroupID using PingOne as a provider, follow these steps:

- Generate the consumer URL and GroupID metadata file for the GroupID client
  with which you want to configure PingOne.
- Configure GroupID in PingOne.
- Configure the PingOne provider in GroupID.

After you complete these steps, you can sign in to GroupID using PingOne.
