# Configure OneLogin SAML Single Sign-On for Directory Manager

OneLogin provides single sign-on and identity management for organizations that use cloud computing.

To configure single sign-on in Directory Manager using OneLogin as a provider, complete these steps:

1. Generate the consumer URL and audience URL for the Directory Manager client you want to configure OneLogin with. See [Generate Consumer and Audience URLs for OneLogin](/docs/directorymanager/11.2/authenticate/asserviceprovider/onelogin/generateurls.md).
2. [Configure Directory Manager in OneLogin](/docs/directorymanager/11.2/authenticate/asserviceprovider/onelogin/configureinonelogin.md).
3. [Configure the OneLogin Provider in Directory Manager](/docs/directorymanager/11.2/authenticate/asserviceprovider/onelogin/configureoneloginindirectorymanager.md).

After you finish, you can sign in to Directory Manager using OneLogin. See [Sign In to Directory Manager Using OneLogin](/docs/directorymanager/11.2/authenticate/asserviceprovider/onelogin/signin.md).
