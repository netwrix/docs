# Policy Template Administration

Edit configuration policy templates, and upload or download them. The default templates provided
with Netwrix Change Tracker are already aligned to default Device Groups, but you can change this
association, along with the make-up of the Configuration Monitoring policy.

:::note
Always click the **Save Changes** button after any edit.
:::


To configure additional File/Folder/Registry Match Pattern definitions, click **Show Advanced
Options**.
