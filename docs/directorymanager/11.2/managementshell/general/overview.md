# Directory Manager General Management Shell Cmdlets

Use the following Management Shell cmdlets to perform general tasks:

- [Get-Computer Cmdlet in Directory Manager](/docs/directorymanager/11.2/managementshell/general/getcomputer.md) – Provides information about a computer object.
- [Get-ConnectedStoreInformation Cmdlet](/docs/directorymanager/11.2/managementshell/general/getconnectedstoreinformation.md) – Provides information about the connected identity store.
- [Get-ConnectedUser Cmdlet](/docs/directorymanager/11.2/managementshell/general/getconnecteduser.md) – Provides information about the connected user.
- [Get-GroupIdInformation](/docs/directorymanager/11.2/managementshell/general/getdirectorymanagerinformation.md) – Provides information about Directory Manager.
- [Get-ImanamiCommand Cmdlet](/docs/directorymanager/11.2/managementshell/general/getimanamicommand.md) – Provides basic information about Directory Manager Management Shell cmdlets.
- [Get-ReplicationStatus Cmdlet](/docs/directorymanager/11.2/managementshell/general/getreplicationstatus.md) – Provides the replication status of objects in an identity store.
- [Get-TombStoneObject Cmdlet](/docs/directorymanager/11.2/managementshell/general/gettombstoneobject.md) – Displays information about tombstone objects.
- [Invoke-Replication Cmdlet](/docs/directorymanager/11.2/managementshell/general/invokereplication.md) – Starts the replication process for all the identity stores or for a specific identity store.
- [New-Container Cmdlet](/docs/directorymanager/11.2/managementshell/general/newcontainer.md) – Creates a new organizational unit.
- [Remove-Container Cmdlet](/docs/directorymanager/11.2/managementshell/general/removecontainer.md) – Removes an empty organizational unit.
- [Restore-TombStoneObject](/docs/directorymanager/11.2/managementshell/general/restoretombstoneobject.md) – Restores tombstone objects from the directory.
- [Send-Notification](/docs/directorymanager/11.2/managementshell/general/sendnotification.md) – Sends notifications to a group or a user.
