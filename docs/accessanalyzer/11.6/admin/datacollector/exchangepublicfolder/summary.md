# ExchangePublicFolder: Summary

The Summary page displays a summary of the configured query. It is a wizard page for all of the
categories.

![Exchange Public Folder Data Collector Wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/exchangepublicfolder/summary.webp)

Click **Finish** to save configuration changes. If you didn't make any changes, click **Cancel**
instead to close the Exchange Public Folder Data Collector Wizard without saving accidental clicks.
