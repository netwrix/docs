# Netwrix Privilege Secure for Access Management v26.07 Documentation

Netwrix Privilege Secure for Access Management enables administrators and help desk staff to do their day-to-day work without the complexity of traditional privileged access management (PAM) tools. It controls the activity that a user performs rather than mapping that user to a standing privileged account. Privilege Secure grants access for a task just in time and with just enough privilege, and removes it when the task ends. The result is a smaller attack surface.

To learn how the product works, start with the [overview](/docs/privilegesecure/26.07/getting-started/overview.md).
