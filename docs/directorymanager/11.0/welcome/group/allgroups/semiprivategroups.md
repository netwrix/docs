# View Semi-Private Groups in GroupID

This view lists only the semi-private groups created using GroupID in the connected identity
store. It doesn't list expired or deleted semi-private groups. To view the expired or deleted groups,
select the [View Expired Groups in GroupID](/docs/directorymanager/11.0/welcome/group/allgroups/allexpiredgroups.md)
or [Restore or Delete Groups in the GroupID Recycle Bin](/docs/directorymanager/11.0/welcome/group/recyclebin/overview.md)
respectively.

You can [Modify Search Directory](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#modify-search-directory) to search semi-private groups and add
[Filter All Groups](/docs/directorymanager/11.0/welcome/group/allgroups/allgroups.md#filter-all-groups) by clicking **Private Group Grid Filters**. All the semi-private groups matching
the filters appear.
