# View Public Groups in Directory Manager

This view lists only the public groups created in Directory Manager for the connected identity store. It doesn't list expired or deleted public groups. To view expired or deleted groups, see [View Expired Groups in Directory Manager](/docs/directorymanager/11.2/portal/group/allgroups/allexpiredgroups.md) or [Restore or Delete Groups in the Directory Manager Recycle Bin](/docs/directorymanager/11.2/portal/group/recyclebin/overview.md).

To search public groups, [Modify Search Directory](allgroups.md#modify-search-directory). To narrow the list, click **Public Group Grid Filters** and [Filter All Groups](allgroups.md#filter-all-groups). All the public groups that match the filters appear.
