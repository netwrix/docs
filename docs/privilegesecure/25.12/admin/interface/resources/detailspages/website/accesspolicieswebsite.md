# Access Policies Tab for Website

The Access Policies tab shows information about the policies associated with the selected resource.

![Access Policies tab on the Website Details page](/images/privilegesecure/25.12/accessmanagement/admin/policy/tab/resources/websitedetailsaccesspolicytab.webp)

The Access Policies tab has the following features:

- **Search** — Searches the table or list for matches to the search string. When the search finds matches, the
  table or list shows only the matching results.
- **Refresh** — Reload the information displayed

The table has the following columns:

- **Name** — Displays the name of the policy. Click the link to view additional details. See the
  [Access Policy Page](/docs/privilegesecure/25.12/admin/interface/accesspolicy/accesspolicy.md) topic for additional information.
- **Description** — Description of the policy

You can resize the table columns and sort them in ascending or descending order.
