This page explains where to find license utilization statistics in Netwrix Privilege Secure for Discovery. The statistics don't override the terms in your software agreement.

## Prerequisites

Enable Access Risk. The license calculation isn't generated until Access Risk is enabled. See [Access Risk reports](./access-risk.md).

## View license utilization

1. In the left-hand menu, select **Configure**, and then open the licensing statistics.

   ![The Configure menu showing the licensing option](/images/privilegesecure/4.2/discovery/admin/reporting/6472622083095_screen_shot_2022-06-01_at_8.50.00_am.webp)

1. Review the license utilization for the prior 90 days.

   ![The license utilization chart for the prior 90 days](/images/privilegesecure/4.2/discovery/admin/reporting/6472622083095_screen_shot_2022-06-01_at_8.49.50_am.webp)

   The chart is broken down by operating system. For Windows, it is further broken down by server and desktop or laptop. You can change the time frame to the prior month or week.

1. Select the **License Use Details** link to see median and daily information.

   ![The license use details showing median and daily counts](/images/privilegesecure/4.2/discovery/admin/reporting/6472622083095_screen_shot_2022-06-03_at_1.54.04_pm.webp)
