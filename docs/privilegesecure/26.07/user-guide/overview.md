# User guide overview

This section is for people who use Privilege Secure to get access, rather than to configure it. You work in the console in a browser, in your own Remote Desktop or SSH client, or in the browser extension.

Every person who signs in is a user. Approvers, reviewers, and auditors do the tasks of a user and some extra tasks. The roles in the console are Administrators, Users, Reviewers, and Auditors. An approver isn't a role. The approvers for a request are the users and groups that the approval workflow of the connection profile names.

## What each audience can do

| Audience | Tasks | Pages |
|---|---|---|
| Users | Sign in, find activities, request sessions, connect, and track your sessions. | [Sign in](/docs/privilegesecure/26_07/user-guide/sign-in), [My Activities](/docs/privilegesecure/26_07/user-guide/my-activities), [Request a session](/docs/privilegesecure/26_07/user-guide/request-session), [Connect to a session](/docs/privilegesecure/26_07/user-guide/connect-session), [Track your sessions](/docs/privilegesecure/26_07/user-guide/my-sessions) |
| Approvers | Approve or deny the requests that wait for you. | [Approve or deny session requests](/docs/privilegesecure/26_07/user-guide/approve-requests) |
| Reviewers | Certify or deny access in an access certification. | [Review an access certification](/docs/privilegesecure/26_07/user-guide/review-access) |
| Auditors | Watch live sessions and replay recorded sessions in your scope. | [Review sessions as an auditor](/docs/privilegesecure/26_07/user-guide/audit-sessions) |

## Ways to connect

- **The console.** Request a session in the console, then launch it from there. See [Connect to a session](/docs/privilegesecure/26_07/user-guide/connect-session).
- **Your own client.** Use Remote Desktop or an SSH client such as PuTTY instead of the browser. See [Connect with your own RDP or SSH client](/docs/privilegesecure/26_07/user-guide/connect-own-client).
- **The browser extension.** Start web sessions from Chrome or Edge. See [Browser extension](/docs/privilegesecure/26_07/user-guide/browser-extension).
- **From outside the network.** Open RDP and SSH sessions in a browser through the Remote Access Gateway portal. See [Sign in to the Remote Access Gateway portal](/docs/privilegesecure/26_07/remote-access-gateway/user-guide/sign-in) and [Browser sessions](/docs/privilegesecure/26_07/remote-access-gateway/user-guide/browser-sessions).

If your organization uses ServiceNow, you can enter a ticket for a session and update the ticket when the session ends. See [Use ServiceNow tickets with sessions](/docs/privilegesecure/26_07/user-guide/servicenow-tickets).

## Before you begin

Get the console address from your administrator, and see [Navigate the console](/docs/privilegesecure/26_07/user-guide/navigate-console) to learn the layout. For the concepts behind activities, access policies, and sessions, see [Key concepts](/docs/privilegesecure/26_07/getting-started/key-concepts).
