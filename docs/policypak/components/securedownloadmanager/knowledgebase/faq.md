# Frequently Asked Questions

## Does Secure Download Manager delete or quarantine downloaded files?

No. Secure Download Manager only prevents direct execution of a downloaded file from the
browser. The file remains in the user's Downloads folder and can be opened from there. The
policy stops impulsive execution directly from the browser prompt, not access to the file itself.

## Which browsers are supported?

Secure Download Manager currently supports:

- Google Chrome
- Microsoft Edge
- Opera
- Mozilla Firefox

Downloads in other browsers aren't intercepted.

## Can Global Settings be configured on the User side?

No. Global Settings are supported on the **Computer side only**. They apply to all users
of the machines that receive the GPO. You can configure Exclusions Policies on either the
Computer or User side.

## Does the policy apply to files downloaded from intranet sites?

Yes, unless you add those sites to an Exclusions Policy. The block applies to all downloads in
supported browsers, regardless of whether the source is an internet or intranet address.
Add your internal download sites to the **URL Pattern** field of an Exclusions Policy if you
want their files to execute normally.

## Can I apply Exclusions Policies to computers instead of users?

Yes. You can configure Exclusions Policies under **Computer Configuration** as well as
**User Configuration**. Computer-side policies apply to every user who logs on to the machine.
Global Settings, however, are always Computer-side only.

## Can I customize the notification shown to users?

Yes. Open **Specify Global Settings P...** and go to the **General** tab. Under
**Text Customization**, enable any combination of the three fields: window title, notification
title, and message body.

Custom text fields also support variables, including:

- `%DOWNLOADED_FILE_NAME%` — the name of the blocked file
- `%DOWNLOADED_FILE_SOURCE_URL%` — the URL the file was downloaded from
- `%DOWNLOADED_FILE_ZONE_ID%` — the Windows Security Zone ID of the file

All standard PolicyPak process variables are also supported.

## Does this require a separate CSE or browser extension?

No. Secure Download Manager uses the same PolicyPak client-side extension (CSE) already
deployed for other components. Keep the CSE up to date to ensure Secure Download Manager
support is included.

## What happens when a user tries to run a blocked file?

The execution attempt is blocked. If **Show Management Notifications** is set to **YES**, the
user sees a notification dialog. The notification auto-closes after the configured number of
seconds (default: 60), or the user can dismiss it manually. The file remains in the Downloads
folder.

## Can Secure Download Manager send an email alert when a file is blocked?

Yes. Open **Specify Global Settings P...**, go to the **Email** tab, and configure the
**Use of email** dropdown and the **Send To** field. The alert contains extended information
about the process and the blocked network activity.

## Does Secure Download Manager work on non-domain-joined machines?

Yes, when policies are delivered through PolicyPak Cloud or an MDM service such as Microsoft
Intune. Group Policy delivery requires domain membership. See the
[MDM & UEM Tools](/docs/policypak/gettingstarted/mdmmanual/overview.md) topics for details.

## What is the difference between Process Mode values?

The **Process Mode** setting in the Exclusions Policy Editor controls how many times the
exclusion is applied for a given file:

| Value | Behavior |
|---|---|
| `always` | The exclusion is applied every time the matched file is executed. |
| `once` | The exclusion is applied on the first execution only. Later attempts for the same file are blocked. |
| `onceOrForced` | The exclusion is applied on the first execution, or whenever execution is forced by policy. |

Use `always` for files that are regularly re-downloaded and re-run, for example update
installers. Use `once` for one-time setup executables where you want to prevent repeated
execution after the initial run.

## Does Secure Download Manager appear in the ADM report?

Yes. Both Global Settings and Exclusions Policies are included in the ADM report generated by
PolicyPak. All configured values — including URL patterns, file extensions, Process Mode, and
Item Level Targeting conditions — appear in the report alongside other component settings.

## What is the difference between "User processes" and "User and System processes" scope?

The **Scope** setting in the Exclusions Policy Editor controls which execution contexts the
exclusion applies to:

- **User processes** — covers only executions initiated by the logged-on user.
- **User and System processes** — covers both user-initiated and system-initiated executions.
  This is the default and is recommended for most environments.
