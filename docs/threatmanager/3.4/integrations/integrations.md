# Integrations

Use these topics to connect Threat Manager to other systems. Threat Manager can forward threats to a SIEM and query other Netwrix product databases when you run investigations. To set up the Netwrix products that send data to Threat Manager, see the [Integration with Other Netwrix Products](/docs/threatmanager/3.4/configuration/netwrix/overview.md) topic. To configure the console's Integrations menu (directory sync, app tokens, credential profiles, email, and other settings), see the [Integrations Interface](/docs/threatmanager/3.4/configuration/integrations/overview.md) topic.
