# SQL: Summary

The Summary page summarizes the configuration settings. It is a wizard page for all of
the categories.

![SQL Data Collector Wizard Summary Page](/images/accessanalyzer/12.0/admin/datacollector/sql/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** instead to
close the SQL Data Collector Wizard without saving accidental clicks.
