# ActiveDirectory: Results

Use the Results page to select the Active Directory object properties to gather. This wizard page
appears for all categories.

![Active Directory Data Collector Wizard Results page](/images/accessanalyzer/12.0/admin/datacollector/activedirectory/results.webp)

Select properties individually, or use the **Check all**, **Uncheck all**, and **Reset to
defaults** buttons. The data collector gathers all selected properties. Available properties vary
based on the category you select.
