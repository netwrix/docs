# Mailbox Cmdlets in Directory Manager

This section covers cmdlets for performing mailbox-specific tasks such as:

- [Get-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/mailbox/getmailbox.md):
  retrieves a mailbox.
- [New-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/mailbox/newmailbox.md): creates
  a new mailbox.
- [Remove-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/mailbox/removemailbox.md):
  deletes a mailbox.
- [Set-Mailbox Cmdlet in Directory Manager](/docs/directorymanager/11.0/managementshell/mailbox/setmailbox.md):
  modifies a mailbox.
