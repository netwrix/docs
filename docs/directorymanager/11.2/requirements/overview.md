# Directory Manager 11.2 System Requirements

This page lists the hardware, operating system, Microsoft Exchange, and database requirements for running Directory Manager 11.2. The prerequisites can vary with your environment.

- [Directory Manager Hardware Requirements](/docs/directorymanager/11.2/requirements/hardware.md)
- [Windows Server Requirements for Directory Manager](/docs/directorymanager/11.2/requirements/windowsserver.md)
- [Directory Manager Supported Exchange Servers](/docs/directorymanager/11.2/requirements/exchangeservers.md)
- [Directory Manager Database Requirements](/docs/directorymanager/11.2/requirements/database.md)

Before installation, the [Run the Directory Manager Preparation Tool](/docs/directorymanager/11.2/install/installer/preparationtool.md) installs the required software and Windows features. For the list of components the tool installs, see [Software the Directory Manager Preparation Tool Installs](/docs/directorymanager/11.2/install/installer/whatprepinstall.md).
