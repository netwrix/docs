# Create Active Directory user objects in Directory Manager

In an Active Directory identity store, you can create the following types of users:

- **User**: see [Create an AD User in Directory Manager](/docs/directorymanager/11.2/portal/user/create/AD/user.md).
- **Mailbox**: see [Create an Active Directory mailbox in Directory Manager](/docs/directorymanager/11.2/portal/user/create/AD/mailbox.md).
- **Contact**: see [Create an Active Directory contact in Directory Manager](/docs/directorymanager/11.2/portal/user/create/AD/contact.md).
