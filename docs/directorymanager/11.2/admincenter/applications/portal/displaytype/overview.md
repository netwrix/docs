# Design a Directory Manager Portal with Display Types

Display types control the layout, appearance, and pages of a Directory Manager portal. They also expose the functionality and data fields you need in the portal.

You can associate multiple identity stores with a portal and design a different portal for each one. Adding links to the navigation bar, adding pages to the portal, and adding fields to pages are some examples. Each associated identity store then gets its own design and functionality.

:::note
Design settings are available for a standard Directory Manager portal, and not for a Self-Service Password Reset portal.
:::

## Customization areas

You can customize the following for a portal:

- **Search Forms:** Control the fields displayed on different search forms and search result pages in a portal. See the [Customize Search Forms in the Directory Manager Portal](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/searchforms.md) and [Customize Search Results in the Directory Manager Portal](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/searchresults.md) topics.
- **Quick Search:** Control the schema attributes that quick search runs on. See the [Customize Quick Search in the Directory Manager Portal](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/quicksearch.md) topic.
- **Properties:** Control which properties of directory objects the portal displays. See the [Customize Properties Pages in Directory Manager](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/objectproperties.md) topic.
- **Toolbars:** Customize the buttons on the portal toolbars. See the [Customize Toolbars in the Directory Manager Portal](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/toolbars.md) topic.
- **Navigation Bar:** Customize the left navigation bar in a portal. See the [Customize the Directory Manager Portal Navigation Bar](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/navigationbar.md) topic.
- **Bad Words List:** Restrict users from entering bad or offensive words while using a portal. See the [Manage the Bad Words List in a Directory Manager Portal](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/badwords.md) topic.
- **Import/Export Attributes:** Specify the schema attributes used for importing and exporting members and additional owners for groups. See the [Set Import and Export Attributes for Group Members and Owners](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/importexport.md) topic.
- **Create Object Wizards:** Control the schema attributes the portal displays for creating different object types. See the [Customize the Create Object Wizards in a Directory Manager Portal](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/createobject.md) topic.
- **Query Attributes:** Control which schema attributes the portal displays for creating queries for Smart Groups and Dynasties. See the [Specify Smart Group Query Attributes in Directory Manager](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/queryattributes.md) topic.
- **Property Validation:** Manage the schema attributes for user profile validation and group attestation. See the [Manage Property Validation Attributes in Directory Manager](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/propertyvalidation.md) topic.
- **Organizational Hierarchy:** Specify the user attributes displayed on the organizational hierarchy chart. See the [Specify Organizational Hierarchy Attributes](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/organizationalhierarchy.md) topic.
- **Card View:** Specify the attributes displayed on an object card. See the [Specify Attributes for the Directory Manager Object Card](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/objectcard.md) topic.
- **Object List View:** Specify the attributes displayed for similar groups on the **Similar Groups** tab in group properties. See the [Specify Attributes for the Directory Manager Object List View](/docs/directorymanager/11.2/admincenter/applications/portal/displaytype/objectlist.md) topic.
