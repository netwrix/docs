# Risk Metric Sets and Frameworks

Netwrix 1Secure includes these risk metric sets:

- **Netwrix**
- **MITRE Tactic** (tactics and mitigations)
- **CIS Controls v8.1**
- **NIST CSF 2.0**
- **PCI DSS 4.0**
- **Zero Trust Identity**

## Netwrix groups

The **Netwrix** metric set groups metrics into these groups:

- **Data**
- **Identity**
- **Infrastructure**
- **Sensitive Data**

## Zero Trust Identity groups

The **Zero Trust Identity** metric set has these groups:

- **Verify Explicitly**
- **Use Least Privilege**
- **Assume Breach**

## NIST CSF 2.0 and CIS Controls v8.1 groups

The **NIST CSF 2.0** groups include **Identify**, **Protect**, and **Detect**.

The **CIS Controls v8.1** groups include these:

- **Account Management (Control 5)**
- **Secure Configuration (Control 4)**
- **Data Protection (Control 3)**
- **Access Control (Control 6)**

## Mapped regulations

A risk can map to these regulations:

- GDPR
- HIPAA
- PCI DSS
- SOX
- ISO 27001
- CCPA/CPRA
- SOC 2
