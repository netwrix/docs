title: "Use the Systems screen"
description: "Find, filter, and export systems on the Systems screen and open a system to update its configuration and inventory."

The **Systems** screen lists the systems that Netwrix Privilege Secure for Discovery manages. Use it to find systems that need follow-up, such as systems with errors or new systems that need Protect Mode.

To open it, select **Management** > **Systems** in the left-hand menu.

![The Systems screen with the Management menu expanded in the left-hand menu](/images/privilegesecure/4.2/discovery/admin/reporting/4413252324887_screen_shot_2021-11-16_at_7.10.27_pm.webp)

![The Systems screen listing systems with their status](/images/privilegesecure/4.2/discovery/admin/reporting/4413252324887_screen_shot_2021-11-12_at_1.03.25_pm.webp)

## Narrow the list with views

The screen provides a list of views that narrow the systems shown.

![The list of available views on the Systems screen](/images/privilegesecure/4.2/discovery/admin/reporting/4413252324887_screen_shot_2021-11-16_at_7.12.42_pm.webp)

## Filter the list

Use the filters to narrow the list further. You can filter by domain, organizational unit (OU), operating system, and time-based criteria.

![The filter options on the Systems screen](/images/privilegesecure/4.2/discovery/admin/reporting/4413252324887_screen_shot_2021-11-16_at_7.15.23_pm.webp)

You can export the result in several formats.

## Open a system

Select a system name in the left-hand column to open the page for that system. From there you can update the system's configuration and inventory.

![A system's page opened from the Systems screen](/images/privilegesecure/4.2/discovery/admin/reporting/4413252324887_screen_shot_2021-11-16_at_7.22.02_pm.webp)

You can bookmark the address of a system's page for quicker access.
