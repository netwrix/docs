# Known issues in 26.07

Netwrix publishes the known issues and fixes for each Netwrix Privilege Secure for Access Management (Privilege Secure) release with the release announcement on the Netwrix Community. Check the announcement for your release before you open a support case:

- [26.07.1 release announcement](https://community.netwrix.com/t/netwrix-privilege-secure-q2-2026-release-26-07-1/136803)
- [26.07.3 release announcement](https://community.netwrix.com/t/patch-version-26-07-3-released-privilege-secure-for-access-management/161358)
- [Privilege Secure for Access Management on the Netwrix Community](https://community.netwrix.com/c/privilege-secure/29)

Problems with a documented fix are in [Troubleshooting](/docs/privilegesecure/26.07/troubleshooting/overview.md). Notes on a specific upgrade step are in [Upgrade Privilege Secure](/docs/privilegesecure/26.07/install/upgrade.md).

## Report an issue

If you hit a problem that isn't covered, collect the logs and contact [Netwrix Support](https://www.netwrix.com/support.html). For the log locations, see [Log files](/docs/privilegesecure/26.07/admin/audit-reporting/log-files.md).
