# Manage Directory Manager Reports

After you generate a report, the report is listed under the template you used to create it. The
Reports list displays the following for each report:

- Report name
- Category
- Created On
- Modified On
- Actions

You can run, edit, download, and delete reports from the Reports list.

## Run a Report

You can run a previously generated report to view the latest data for it.

Step 1 – In the Directory Manager portal, select **Reports** from the left pane.

Step 2 – On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose
report you generated and click the template that you used.

The template page lists the generated report.

Step 3 – Click the **Run arrow** icon next to the report. The report runs and appears on
the page.

## Edit a Report

When you generate a report, the Directory Manager portal saves the settings provided in the respective
report. You can launch this wizard again for a report and edit the settings.

Step 1 – In the Directory Manager portal, select **Reports** from the left pane.

Step 2 – On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose
report you generated and click the template that you used.

The template page lists the generated report.

Step 3 – Click the **Edit** icon next to the report and follow
[In Step 1 of generating a report:](/docs/directorymanager/11.2/portal/reports/generate.md). Make the relevant changes and click **Finish** to
generate the report.

## Download a Report

You can also download a report directly from the Report listing page.

Step 1 – In the Directory Manager portal, select **Reports** from the left pane.

Step 2 – On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose
report you generated and click the template that you used.

The template page lists the generated report.

Step 3 – Click the **Download** icon next to the report and select one of the following formats to
download the report:

1. Excel
2. PDF
3. HTML

## Delete a Report

When you delete a report, all its settings are removed.

Step 1 – In the Directory Manager portal, select **Reports** from the left pane.

Step 2 – On Reports Portal, select the type of object (User, Group, Computer, or Contact) whose
report you generated and click the template that you used.

The template page lists the generated report.

Step 3 – Click the **Delete** button next to the report. The report is permanently deleted.
