# Create User, Mailbox, and Contact Objects

In the Directory Manager portal, you can create the following types of user objects:

- User
- Mailbox
- Contact

Directory Manager supports these identity providers for creating user objects:

- Active Directory
- Microsoft Entra ID
- Generic LDAP
- Google Workspace
