# CLU: Summary

The Summary page provides a summary of the query you created or edited. It is a wizard
page for all profile types.

![Command Line Utility Data Collector Wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/commandlineutility/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** to close
the Command Line Utility Data Collector Wizard and avoid saving accidental clicks.
