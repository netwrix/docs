# TextSearch: Summary

The Summary page displays a summary of the configured query.

![Text Search Data Collector Wizard Summary page](/images/accessanalyzer/11.6/admin/datacollector/textsearch/summary.webp)

Click **Finish** to save configuration changes. If you made no changes, click **Cancel** to close
the Text Search Data Collector Wizard instead. This prevents the wizard from saving accidental
clicks.
